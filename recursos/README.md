## 🛠️ Herramientas imprescindibles

### Editor / IDE
- **VS Code** — el estándar.
- **WebStorm** — IDE completo (pago, pero muy bueno).
- **Zed** — editor minimalista y rápido.

### Navegador
- **Chrome** con DevTools.
- **Firefox Developer Edition** — mejores herramientas de CSS Grid.
- **Safari** — obligatorio para testear iOS.

### Extensiones Chrome / Firefox
- **React Developer Tools**.
- **axe DevTools** — a11y scanner.
- **Lighthouse** — ya viene con DevTools.
- **WAVE** — otra a11y scanner.
- **JSON Viewer** — para APIs.
- **ColorZilla** — color picker.

### Diseño
- **Figma** · https://figma.com — colaborativo, gratis para proyectos personales.
- **Excalidraw** · https://excalidraw.com — wireframes rápidos.
- **Coolors** · https://coolors.co — generador de paletas.
- **Fontpair** · https://fontpair.co — combinaciones de fuentes.

### Assets
- **Heroicons** · https://heroicons.com — iconos.
- **Lucide** · https://lucide.dev — iconos.
- **Phosphor** · https://phosphoricons.com.
- **Unsplash** · https://unsplash.com — fotos.
- **Undraw** · https://undraw.co — ilustraciones.
- **Squoosh** · https://squoosh.app — compresión de imágenes.

### Testing / Calidad
- **Lighthouse** (DevTools o CLI).
- **WebPageTest** · https://www.webpagetest.org.
- **Wave** · https://wave.webaim.org.
- **Contrast Checker** · https://webaim.org/resources/contrastchecker/.
- **Can I Use** · https://caniuse.com — compatibilidad de features.
- **BrowserStack** / **LambdaTest** — testing cross-browser.

### API / Data
- **JSONPlaceholder** · https://jsonplaceholder.typicode.com — API fake para practicar.
- **PokéAPI** · https://pokeapi.co.
- **OpenLibrary** · https://openlibrary.org/developers/api.
- **TMDB** · https://www.themoviedb.org/documentation/api.
- **Open-Meteo** · https://open-meteo.com (clima gratis, sin API key).
- **httpbin.org** · https://httpbin.org — endpoints de testing.

### Hosting / Deploy
- **Vercel** · https://vercel.com (ideal para React/Next).
- **Netlify** · https://netlify.com (gran DX).
- **Cloudflare Pages** · https://pages.cloudflare.com (muy rápido).
- **GitHub Pages** · https://pages.github.com (simple).
- **Railway** / **Render** — si necesitás backend.

### Utilidades
- **Bundlephobia** · https://bundlephobia.com — peso de paquetes npm.
- **Regex101** · https://regex101.com.
- **Repl.it** / **CodeSandbox** / **StackBlitz** — playgrounds online.
- **Transform** · https://transform.tools — conversiones entre formatos (JSON↔YAML, etc).
