📝 Notas Markdown

🎯 Objetivo: un editor de notas tipo "segundo cerebro": escribís en Markdown a la izquierda, ves el preview renderizado a la derecha en vivo, buscás entre tus notas, y todo persiste localmente. Una app que de verdad vas a usar.

Qué vas a aprender

  • Estado de una colección (lista de notas) con CRUD.
  • Renderizar Markdown de forma segura (sanitización).
  • Persistencia robusta con custom hook + localStorage.
  • Búsqueda/filtro en vivo.
  • Layout de 2 paneles (editor + preview).
  • UX: autoguardado, debounce, estados vacíos.

Stack

React + Vite + marked (parser Markdown) + DOMPurify (sanitizar HTML). Persistencia: localStorage.

Fases

Fase 1 — Editor + preview en vivo. Un textarea controlado a la izquierda; su contenido renderizado como HTML a la derecha.
