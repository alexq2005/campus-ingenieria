🧠 Red Neuronal desde Cero

🎯 Objetivo: construir una red neuronal desde cero, sin TensorFlow ni PyTorch — solo arrays y matemática. Vas a escribir el forward pass, la backpropagation y el descenso de gradiente a mano, y vas a ver a la red razonar un patrón: ajustar sus pesos hasta doblar una frontera de decisión que separa dos clases. Es el proyecto que destapa la caja negra: después de esto, ningún framework de IA te va a parecer magia.

▶ Entrenar la red REAL en vivo
No es una maqueta — es una red 2→oculta→1 con backprop escrito a mano. Cambiá el dataset, el learning rate y las neuronas, y mirá la frontera formarse píxel a píxel.

Cómo funciona — forward, error, backprop, repetir

Qué vas a aprender

  • Qué es de verdad una neurona: activación(Σ wᵢxᵢ + b).
  • El forward pass: cómo fluye un dato de la entrada a la predicción.
  • Backpropagation con la regla de la cadena — repartir el error a cada peso.
  • Descenso de gradiente: w ← w − lr · ∂L/∂w (lo de M40, pero en una red entera).
  • Por qué XOR necesita una capa oculta (el problema que congeló la IA en los 70).
  • Hiperparámetros: learning rate, tamaño de la capa, sobreajuste vs generalización.
🔗 Conexión con el campus: este proyecto materializa M40 Deep Learning (forward, backprop, el simulador de gradient descent), M03 Cálculo (derivadas = gradiente) y M02 Álgebra Lineal (vectores y matrices de pesos) y el M14 NumPy del Curso de Python (la sintaxis exacta para escribirlo: @, reshape, np.tanh). Es el paso previo a usar un framework: una vez que entendés esto, el P16 Clasificador CNN deja de ser una caja negra.

Stack

JavaScript puro + <canvas>. Cero librerías — la idea es escribir vos la matemática. (En "producción" usarías PyTorch/TensorFlow, pero acá el objetivo es entender el motor.)

Fases

Fase 1 — Una neurona y el forward pass. Una neurona toma entradas, las pondera, suma un sesgo y pasa todo por una activación no-lineal (acá tanh en la capa oculta, sigmoide en la salida para dar una probabilidad 0–1).
// Red: 2 entradas → H neuronas ocultas (tanh) → 1 salida (sigmoide)
function forward(x0, x1) {
  const a1 = new Array(H);
  for (let i = 0; i < H; i++) {
    const z = W1[i][0]*x0 + W1[i][1]*x1 + b1[i];  // suma ponderada
    a1[i] = Math.tanh(z);                          // activación no-lineal
  }
  let z2 = b2;
  for (let i = 0; i < H; i++) z2 += W2[i] * a1[i];
  const out = 1 / (1 + Math.exp(-z2));             // sigmoide → probabilidad
  return { a1, out };
}
Fase 2 — Medir el error. Comparás la predicción ŷ con la etiqueta real y. Para clasificación se usa entropía cruzada binaria (BCE): castiga fuerte estar seguro y equivocado.
// BCE: -[ y·log(ŷ) + (1-y)·log(1-ŷ) ]   (ε evita log(0))
loss += -(y * Math.log(out + 1e-7) + (1 - y) * Math.log(1 - out + 1e-7));
Fase 3 — Backpropagation (el corazón). El error vuelve hacia atrás por la regla de la cadena, calculando cuánto contribuyó cada peso. Con BCE + sigmoide, el gradiente de la salida se simplifica hermosamente a (ŷ − y).
const dz2 = out - y;                       // ✨ gradiente de la salida (BCE+sigmoide)

// capa de salida
for (let i = 0; i < H; i++) W2[i] -= lr * dz2 * a1[i];
b2 -= lr * dz2;

// capa oculta (derivada de tanh = 1 - a²)
for (let i = 0; i < H; i++) {
  const dz1 = dz2 * W2[i] * (1 - a1[i]*a1[i]);
  W1[i][0] -= lr * dz1 * x0;
  W1[i][1] -= lr * dz1 * x1;
  b1[i]    -= lr * dz1;
}
El -= lr * gradiente ES el descenso de gradiente: movés cada peso un pasito en la dirección que baja el error. Repetir esto por todos los datos, muchas épocas, es todo lo que significa "entrenar una red".
Fase 4 — Visualizar el razonamiento. Pintá el <canvas>: para cada píxel corré forward() y coloreá según la clase que la red predice. Encima dibujá los puntos reales. Vas a ver la frontera de decisión doblarse a medida que entrena.
✅ Terminado cuando:
  • La red aprende XOR con ≥4 neuronas ocultas (y NO lo logra con 1 — comprobalo).
  • La pérdida baja época a época y la precisión sube hacia 100%.
  • Ves la frontera de decisión formarse en el canvas en tiempo real.
  • Subir el learning rate demasiado desestabiliza el entrenamiento (lo ves).
  • Resolvés círculo y espiral subiendo las neuronas ocultas.

Variantes para subir de nivel

  1. Más capas: agregá una segunda capa oculta (red "profunda") y generalizá el backprop.
  2. Otras activaciones: probá ReLU en vez de tanh y compará la velocidad de aprendizaje.
  3. Mini-batch + momentum: en vez de SGD puro, promediá gradientes y agregá inercia.
  4. Regularización: L2 o dropout para frenar el sobreajuste en la espiral.
  5. Dibujar tu propio dataset: clickear en el canvas para poner puntos de cada clase.
  6. Migrar a un framework: reimplementá lo mismo en PyTorch y verás que hace exactamente esto, pero con autograd. → P16.
