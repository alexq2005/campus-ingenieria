🔥 Alerta Temprana de Incendios Forestales

🌍 El problema: los incendios forestales se multiplican con el cambio climático y arrasan bosques, casas y vidas. La clave es el tiempo: un fuego detectado en los primeros minutos se apaga; uno detectado por satélite horas después ya es catástrofe. A quién ayuda: bomberos, comunidades rurales y reservas naturales — una red de nodos baratos en el monte avisa cuando todavía se puede actuar.
🎯 Objetivo: nodos autónomos (solares) repartidos en una zona boscosa que detectan humo, temperatura y CO, y al confirmar señales de fuego transmiten una alerta por radio de largo alcance (LoRa) —sin depender de WiFi/celular— a una central que ubica el foco en un mapa.
🔗 Conexión con el campus: E05 Sensores (humo, gas, temperatura), E03/E04 (bajo consumo, deep sleep), M15 Redes (topología, LoRa) y M37 IoT.

Cómo funciona — red de nodos sin cobertura celular

Qué vas a aprender

  • Detectar fuego con varios sensores (humo + CO + temperatura) y fusionar señales para evitar falsas alarmas (E05).
  • LoRa: comunicación de largo alcance y bajo consumo donde no hay cobertura (M15).
  • Diseño de ultra bajo consumo (deep sleep, solar) para meses sin mantenimiento (E03).
  • Topología de red en cadena/malla y confiabilidad de la alerta.
  • Geolocalizar el foco y mostrarlo en un mapa de la central.
  • Robustez: el sistema debe funcionar justo cuando todo se está quemando.

Componentes

ESP32 con LoRa (TTGO LoRa32) · sensor de humo/gas MQ-2/MQ-135 · termistor o sensor IR de temperatura · panel solar + batería · caja resistente. Gateway LoRa → internet en un punto alto.

Código clave (fusión de sensores + deep sleep)

// Confirmar fuego con MÚLTIPLES señales evita falsas alarmas (E05)
bool posibleFuego = (humo > UMBRAL_HUMO)
                 && (temp > UMBRAL_TEMP)
                 && (co  > UMBRAL_CO);

if (posibleFuego) {
  loRaEnviar(nodoID, lat, lon, humo, temp);   // alerta de largo alcance (M15)
} else {
  // Ultra bajo consumo: dormir y revisar cada pocos minutos (E03)
  esp_sleep_enable_timer_wakeup(5 * 60 * 1000000ULL);
  esp_deep_sleep_start();        // meses con una batería + panel solar
}
🔗 Dos ideas clave: fusión de sensores (humo Y temperatura Y CO juntos) para no disparar la alarma con una parrilla lejana, y deep sleep (E03) — el nodo duerme el 99% del tiempo para durar meses con un panelcito solar. LoRa (M15) es la pieza que permite todo esto donde no llega ninguna otra red.

Fases

Fase 1: leé los sensores de humo/gas/temperatura y caracterizá sus respuestas (probá con humo de una vela, con cuidado).
Fase 2: lógica de fusión: confirmar fuego solo con varias señales. Medí falsas alarmas.
Fase 3: enlace LoRa punto a punto entre un nodo y el gateway. Medí el alcance real.
Fase 4: deep sleep + solar: que un nodo viva días con batería. Medí el consumo.
Fase 5: central que recibe, ubica el nodo en un mapa y dispara la alerta.
✅ Terminado cuando:
  • Detecta una fuente de humo/calor controlada y descarta falsas alarmas.
  • La alerta viaja por LoRa cientos de metros / km sin WiFi ni celular.
  • Un nodo funciona días con batería gracias al deep sleep.
  • La central ubica el foco en un mapa con su ID y hora.
  • El sistema prioriza no perder un fuego real (sensibilidad alta) sin saturar de falsas alarmas.

Variantes

  1. Red en malla: los nodos se retransmiten entre sí para cubrir más área.
  2. TinyML para reconocer el patrón de un incendio real vs ruido (M40).
  3. Cruce con datos de viento/humedad para estimar propagación.
  4. Aplicar la misma red a alerta de inundaciones (ver el otro proyecto).
  5. Cámaras en puntos altos con detección de humo por visión (M42).
