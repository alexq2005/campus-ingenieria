🖼️ Clasificador de Imágenes (CNN)

🎯 Objetivo: entrenar una red neuronal convolucional que mire una imagen y diga qué es (un dígito, una prenda, un animal). Vas a ir de píxeles crudos a una predicción con confianza, entendiendo por qué la convolución es la operación que hizo posible la visión por computadora moderna.
🔗 Conexión con el campus: M40 Deep Learning (CNN, backprop), M39 ML (train/test, overfitting), M42 Visión y Python (tensores, vectorización).

Cómo funciona — de píxeles a clase

Qué vas a aprender

  • Qué hace una convolución y por qué gana a una red densa en imágenes.
  • El ciclo de entrenamiento: forward → loss → backprop → step (M40).
  • Separar train / validation / test y detectar overfitting (M39).
  • Data augmentation, normalización, learning rate.
  • Evaluar con matriz de confusión, no solo accuracy.
  • Guardar el modelo y usarlo para predecir imágenes nuevas (inferencia).

Stack

Python · PyTorch (o TensorFlow/Keras) · datasets MNIST o Fashion-MNIST (incluidos, sin descargar nada raro) · matplotlib para visualizar. Corre en CPU; GPU acelera pero no es obligatoria. Empezá en Google Colab si no querés instalar nada.

Código clave (el ciclo de entrenamiento)

import torch, torch.nn as nn

class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(1, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        )
        self.fc = nn.Linear(32 * 7 * 7, 10)   # 10 clases

    def forward(self, x):
        x = self.conv(x)
        return self.fc(x.flatten(1))

model, opt = CNN(), None
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.CrossEntropyLoss()

for imgs, labels in train_loader:          # un batch
    pred = model(imgs)                      # forward
    loss = loss_fn(pred, labels)            # qué tan mal
    opt.zero_grad(); loss.backward()        # backprop (M40)
    opt.step()                              # ajustar pesos
🔗 loss.backward() es el descenso por gradiente de M40: calcula cuánto contribuyó cada peso al error y lo corrige. Es el mismo "medir error → ajustar → repetir" del control de E08, pero sobre millones de parámetros en vez de un motor.

Fases

Fase 1: cargá MNIST, visualizá ejemplos, entrená una red densa simple como baseline. Anotá su accuracy.
Fase 2: reemplazá por una CNN. Compará: debería superar al baseline claramente.
Fase 3: separá validation, graficá train vs val loss. Detectá y combatí el overfitting (dropout, augmentation).
Fase 4: matriz de confusión: ¿qué clases confunde? Probá con Fashion-MNIST (más difícil).
Fase 5: guardá el modelo y hacé una mini-app que clasifique una imagen que vos dibujes.
✅ Terminado cuando:
  • Tu CNN supera el 98% en MNIST (o ~90% en Fashion-MNIST).
  • Mostrás con gráficos que NO estás sobreajustando (val loss no se dispara).
  • Entendés y explicás la matriz de confusión.
  • Podés clasificar una imagen nueva, fuera del dataset.
  • Sabés decir qué hace cada capa, no solo que "funciona".
