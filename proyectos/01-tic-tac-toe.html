Proyecto 01 🟢 Principiante ⏱ ~3-5 horas React / JS

⭕ Tic-Tac-Toe (Ta-Te-Ti)

🎯 Objetivo: construir el juego del Ta-Te-Ti jugable de a dos en el mismo dispositivo. Es el proyecto que la propia documentación oficial de React usa para enseñar — porque concentra los conceptos base en algo divertido y acotado.

Qué vas a aprender

  • Manejar estado con useState (el tablero, el turno).
  • Renderizar una grilla desde un array con .map() y keys.
  • Inmutabilidad: actualizar el tablero sin mutarlo.
  • Lógica derivada: calcular el ganador desde el estado, no guardarlo aparte.
  • Pasar callbacks como props de padre a hijo.

Stack

React + Vite. Sin librerías extra. CSS plano.

Fases

Fase 1 — El tablero estático. Renderizá 9 casillas desde un array de 9 elementos. Cada casilla es un <button>.
function App() {
  const [casillas, setCasillas] = useState(Array(9).fill(null));

  return (
    <div style={{ display:'grid', gridTemplateColumns:'repeat(3,80px)', gap:4 }}>
      {casillas.map((valor, i) => (
        <button key={i} style={{ height:80, fontSize:32 }}>
          {valor}
        </button>
      ))}
    </div>
  );
}
Fase 2 — Jugar. Al clickear una casilla vacía, poné "X" u "O" según el turno. Sin mutar el array.
const [esX, setEsX] = useState(true);

function jugar(i) {
  if (casillas[i]) return;          // ya ocupada → ignorar
  const nuevas = [...casillas];     // ✅ copia, no mutar
  nuevas[i] = esX ? 'X' : 'O';
  setCasillas(nuevas);
  setEsX(!esX);
}
// en el botón: onClick={() => jugar(i)}
Fase 3 — Detectar ganador. Calculalo en cada render (derivado), comparando las 8 líneas ganadoras.
function calcularGanador(c) {
  const lineas = [
    [0,1,2],[3,4,5],[6,7,8],   // filas
    [0,3,6],[1,4,7],[2,5,8],   // columnas
    [0,4,8],[2,4,6],           // diagonales
  ];
  for (const [a,b,d] of lineas) {
    if (c[a] && c[a] === c[b] && c[a] === c[d]) return c[a];
  }
  return null;
}

const ganador = calcularGanador(casillas);  // derivado, NO en useState
Fase 4 — Estado del juego + reinicio. Mostrá "Gana X", "Empate" o "Turno de O". Botón para reiniciar.
🔗 Conexión con el campus: esto aplica directo lo de M03 useState (inmutabilidad), M05 Listas y Keys (renderizar la grilla) y M02 Props (si extraés un componente Casilla). El "ganador derivado" es exactamente la lección de "no guardes lo que podés calcular".
✅ Terminado cuando:
  • Dos personas pueden jugar una partida completa.
  • Detecta correctamente las 8 formas de ganar + empate.
  • No deja sobrescribir una casilla ocupada.
  • El botón "Reiniciar" vuelve todo a cero.

Variantes para subir de nivel

  1. Historial + viaje en el tiempo: guardá cada estado del tablero y permití "volver" a una jugada anterior (la versión completa del tutorial oficial de React).
  2. IA simple: que "O" juegue solo eligiendo una casilla random, o con minimax (imbatible).
  3. Tablero NxN: generalizalo a 4×4 o 5×5.
  4. Persistencia: guardá la partida en localStorage (usá el custom hook de M08).
  5. Online: dos jugadores en dispositivos distintos (necesitás WebSockets — proyecto avanzado).
