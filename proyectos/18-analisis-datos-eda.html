📊 Análisis Exploratorio de Datos (EDA)

🎯 Objetivo: tomar un dataset real y crudo, limpiarlo y convertirlo en insights y gráficos que cuenten una historia. El EDA es el trabajo invisible que precede a todo modelo: el 80% del tiempo de un data scientist es entender y arreglar los datos, no entrenar modelos.
🔗 Conexión con el campus: M39 ML (estadística, features), M43 Data Engineering (limpieza, pipelines), Python (estructuras de datos) y I/O (CSV/JSON).

El flujo del EDA

Qué vas a aprender

  • Cargar y explorar datos con pandas (head, info, describe).
  • Limpiar: valores nulos, duplicados, tipos mal inferidos, outliers.
  • Agregar y resumir con groupby y tablas pivote.
  • Visualizar: histogramas, boxplots, correlaciones, series temporales.
  • Distinguir correlación de causalidad y comunicar honestamente.
  • Documentar el análisis en un notebook reproducible.

Stack

Python · pandas · matplotlib / seaborn · Jupyter notebook. Datasets sugeridos: Titanic, precios de viviendas, datos abiertos de tu ciudad/gobierno, o tus propios datos (gastos, fitness, el log del Invernadero P15).

Código clave (limpieza + insight)

import pandas as pd

df = pd.read_csv("datos.csv")

# 1) Diagnóstico
print(df.info())            # tipos y nulos por columna
print(df.describe())        # estadísticas de las numéricas

# 2) Limpieza
df = df.drop_duplicates()
df["edad"] = df["edad"].fillna(df["edad"].median())   # imputar nulos
df = df[df["precio"] > 0]                              # quitar imposibles

# 3) Insight con groupby
resumen = (df.groupby("categoria")["precio"]
             .agg(["mean", "count"])
             .sort_values("mean", ascending=False))
print(resumen)              # ¿qué categoría es más cara y cuántas hay?
🔗 El groupby es el patrón split-apply-combine: partís por categoría, aplicás una agregación, recombinás. Es la misma idea de map/reduce (Python funcional) y la base de toda consulta GROUP BY en SQL (M19) — verlo en pandas te prepara para ambos.

Fases

Fase 1: elegí un dataset, cargalo y hacé el diagnóstico inicial (¿cuántas filas? ¿qué falta? ¿qué tipos?).
Fase 2: limpieza completa: nulos, duplicados, tipos, outliers. Documentá cada decisión.
Fase 3: 5 preguntas concretas al dataset y respondelas con groupby/pivot.
Fase 4: visualizaciones: al menos un histograma, un boxplot y un mapa de correlación.
Fase 5: escribí un resumen de 1 página con tus 3 hallazgos principales y sus límites.
✅ Terminado cuando:
  • El notebook corre de principio a fin sin errores y es reproducible.
  • Documentaste por qué imputaste/eliminaste cada cosa (no a ciegas).
  • Tenés 3 insights respaldados con números y gráficos.
  • Distinguís lo que los datos muestran de lo que NO prueban (causalidad).
  • Un lector que no vio los datos entiende tu conclusión.
