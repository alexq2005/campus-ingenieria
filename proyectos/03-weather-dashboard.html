Proyecto 03 🔵 Intermedio ⏱ ~1 semana React + APIs

🌦️ Weather Dashboard

🎯 Objetivo: una app que muestra el clima actual y el pronóstico de cualquier ciudad, con gráfico de temperatura, búsqueda y ciudades favoritas. Es EL proyecto para dominar consumir APIs reales — la habilidad #1 del frontend moderno.

Qué vas a aprender

  • Fetch async a una API externa con loading / error / success states.
  • Manejar API keys y variables de entorno (.env).
  • Data fetching con TanStack Query (cache, refetch).
  • Renderizar gráficos (Recharts).
  • Persistir favoritos con custom hook + localStorage.
  • Debounce en la búsqueda para no spamear la API.

Stack

React + Vite + TanStack Query + Recharts. API gratuita: Open-Meteo (no requiere API key) o OpenWeatherMap (con key gratis).

Fases

Fase 1 — Fetch básico. Pedí el clima de una ciudad fija y mostralo. Manejá los 3 estados.
import { useQuery } from '@tanstack/react-query';

function useClima(lat, lon) {
  return useQuery({
    queryKey: ['clima', lat, lon],
    queryFn: async () => {
      const url = `https://api.open-meteo.com/v1/forecast?latitude=${lat}&longitude=${lon}¤t=temperature_2m,relative_humidity_2m&hourly=temperature_2m`;
      const res = await fetch(url);
      if (!res.ok) throw new Error('Error al obtener el clima');
      return res.json();
    },
  });
}

Fase 2 — Búsqueda de ciudad. Input que busca ciudades (geocoding API) con debounce, y al elegir una, carga su clima.
// Custom hook de M08 — evita llamar la API en cada tecla
function useDebounce(value, delay = 400) {
  const [d, setD] = useState(value);
  useEffect(() => {
    const t = setTimeout(() => setD(value), delay);
    return () => clearTimeout(t);
  }, [value, delay]);
  return d;
}

✅ Terminado cuando:
  • Buscás cualquier ciudad y ves su clima actual.
  • Hay un gráfico del pronóstico de las próximas horas.
  • Podés guardar/quitar favoritos y persisten al recargar.
  • Maneja errores (ciudad no encontrada, API caída) sin romperse.
  • Está deployado en Vercel con URL pública.

Variantes

  1. Geolocalización: detectar la ubicación del usuario con navigator.geolocation.
  2. Mapa con la ciudad (Leaflet).
  3. Alertas: notificar si va a llover en las próximas horas.
  4. Comparar 2 ciudades lado a lado.
  5. Modo offline: mostrar el último dato cacheado si no hay red.
