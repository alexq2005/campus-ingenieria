🌾 Riego Inteligente de Subsistencia

🌍 El problema: la agricultura usa el 70% del agua dulce del planeta, y gran parte se desperdicia regando de más o en el momento equivocado. Para un pequeño agricultor en zona árida, el agua es escasa y cada cosecha define el año. A quién ayuda: familias de agricultura de subsistencia y huertas comunitarias — regar la cantidad justa en el momento justo significa más comida con menos agua.
🎯 Objetivo: un sistema de riego por goteo automático que riega según la humedad real del suelo (no por un reloj), funciona con energía solar y es lo bastante barato y robusto para el campo. Maximiza la cosecha por litro de agua.
🔗 Conexión con el campus: E08 Control (lazo cerrado, histéresis), E05 (sensor de suelo, válvula/bomba), E00 (energía solar, baterías) y el P15 Invernadero (hermano de este proyecto).

Por qué regar por humedad y no por reloj

Qué vas a aprender

  • Control por histéresis sobre la humedad del suelo (E08).
  • Sensores de humedad capacitivos (los resistivos se corroen) (E05).
  • Accionar una válvula/bomba de bajo consumo (E05/E00).
  • Diseño solar + batería para autonomía total en el campo (E00).
  • Robustez: que funcione meses al sol, la lluvia y el polvo sin mantenimiento.
  • Medir el ahorro de agua real vs riego manual.

Componentes

ESP32/Arduino (deep sleep) + sensor de humedad capacitivo + electroválvula 12V o bomba + relé/MOSFET · panel solar pequeño + batería + cargador solar · manguera de goteo. Bajo costo y reparable con piezas comunes.

Código clave (riego por histéresis + ahorro de energía)

const int SECO   = 40;   // % humedad: por debajo → regar
const int HUMEDO = 60;   // % humedad: por encima → cortar
bool regando = false;

void cicloRiego() {
  int h = leerHumedadSuelo();          // capacitivo (E05)

  if (!regando && h < SECO) {
    abrirValvula(); regando = true;     // empezar a regar
  } else if (regando && h > HUMEDO) {
    cerrarValvula(); regando = false;   // suelo ya húmedo → cortar (ahorro)
  }

  // Dormir entre chequeos: el suelo cambia lento, no hace falta vigilar siempre
  esp_sleep_enable_timer_wakeup(15 * 60 * 1000000ULL);  // cada 15 min (E03)
  esp_deep_sleep_start();               // batería dura semanas con poco panel
}
🔗 Es el mismo lazo de histéresis del Invernadero (P15) y de E08, pero optimizado para el campo: el deep sleep (E03) hace que un panel solar chico alcance, porque el suelo cambia lento y no hace falta medir cada segundo. Ahorro de agua + ahorro de energía, los dos por diseño.

Fases

Fase 1: calibrá el sensor capacitivo (seco al aire vs sumergido). Mapealo a 0-100%.
Fase 2: control por histéresis abriendo/cerrando la válvula con una maceta de prueba.
Fase 3: alimentación solar + batería. Medí cuánto dura y ajustá el deep sleep.
Fase 4: robustez de campo: proteger electrónica del agua/sol, válvula confiable, fail-safe (si falla, no inundar ni dejar secar).
Fase 5: medí el ahorro: litros usados vs riego manual, para la misma planta.
✅ Terminado cuando:
  • El sistema mantiene la humedad del suelo en su banda sin intervención por días.
  • Funciona solo con energía solar (autónomo en el campo).
  • Demostrás un ahorro de agua medible frente al riego manual/por reloj.
  • La electrónica sobrevive a la intemperie y tiene un comportamiento seguro ante fallas.
  • Es barato y reparable con piezas accesibles.

Variantes

  1. Varias zonas con cultivos distintos, cada una con su umbral.
  2. Integrar pronóstico de lluvia: no regar si va a llover (API + WiFi/LoRa).
  3. Telemetría a un panel para una cooperativa de agricultores (P14 MQTT).
  4. Recolección de agua de lluvia con medición de tanque.
  5. Modelo que aprende la curva de cada cultivo (M39).
