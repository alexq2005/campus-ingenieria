🎵 Vúmetro con FFT

🎯 Objetivo: un visualizador de audio que descompone el sonido en frecuencias (graves, medios, agudos) y las muestra como barras de LED que bailan con la música. Es la FFT de E07 hecha luz — vas a VER el espectro de frecuencias en tiempo real.
🔗 Conexión con el campus: aplica directo E07 DSP (FFT, espectro), E06 Señales (dominio frecuencia, Nyquist), E03 (ADC del micrófono) y E05 (tira LED como actuador).

Cómo funciona — el flujo de la señal

La idea visual: de onda a espectro

Qué vas a aprender

  • Capturar audio con un micrófono I2S o analógico + ADC (E03).
  • Correr una FFT en el ESP32 en tiempo real (edge DSP, E07).
  • Agrupar el espectro en bandas (graves/medios/agudos).
  • Controlar una tira LED direccionable (WS2812/NeoPixel, E05).
  • Respetar Nyquist (E06): muestrear a >2× la frecuencia máxima.

Componentes

ESP32 · micrófono INMP441 (I2S) o MAX9814 (analógico) · tira LED WS2812 (8-30 LEDs) · fuente 5V. Simulable parcialmente en Wokwi.

Código clave (la FFT en el chip)

#include <arduinoFFT.h>

#define MUESTRAS 512
#define FS 40000          // 40 kHz → Nyquist permite hasta 20 kHz (E06)

double vReal[MUESTRAS], vImag[MUESTRAS];
ArduinoFFT<double> FFT(vReal, vImag, MUESTRAS, FS);

void loop() {
  // 1) Capturar MUESTRAS del micrófono (ADC, E03)
  for (int i = 0; i < MUESTRAS; i++) {
    vReal[i] = analogRead(34);
    vImag[i] = 0;
    delayMicroseconds(1000000 / FS);
  }

  // 2) FFT — tiempo → frecuencia (E07)
  FFT.windowing(FFT_WIN_TYP_HAMMING, FFT_FORWARD);  // ventana (evita leakage)
  FFT.compute(FFT_FORWARD);
  FFT.complexToMagnitude();

  // 3) Agrupar en bandas y pintar LEDs (E05)
  for (int banda = 0; banda < NUM_BANDAS; banda++) {
    double energia = energiaDeBanda(vReal, banda);
    int altura = map(energia, 0, MAX, 0, LEDS_POR_BANDA);
    pintarBarra(banda, altura);
  }
}
🔗 Notá el FFT_WIN_TYP_HAMMING: es la ventana que E07 explica — sin ella, los bordes del segmento generan frecuencias falsas (spectral leakage). Y el FS=40000 respeta Nyquist (E06) para cubrir el rango audible.

Fases

Fase 1: capturá audio y mandá los valores crudos por serial. Verificá que el micrófono responde al sonido.
Fase 2: corré la FFT y mostrá el espectro por serial (números). Silbá distintos tonos y mirá moverse el pico.
Fase 3: conectá la tira LED. Una barra por banda, altura según energía.
Fase 4: suavizado (filtro de E07), colores por banda, modo "pico que cae" (estética).
✅ Terminado cuando:
  • Las barras de LED reaccionan a la música en tiempo real.
  • Los graves mueven las barras de un lado y los agudos del otro (separación real de frecuencias).
  • La FFT corre en el chip sin lag perceptible.
  • Aplicaste ventana (Hamming) y respetás Nyquist.
  • Grabaste un video del vúmetro bailando (va al portfolio).

Variantes

  1. Matriz LED 2D (espectrograma: frecuencia × tiempo, conecta con M42 Visión).
  2. Modo "beat detection": detectar el ritmo y pulsar con el bombo.
  3. Enviar el espectro por WiFi a un dashboard web (Curso-React + M37).
  4. Reconocimiento de notas musicales (la frecuencia del pico → nota).
  5. TinyML: clasificar género o instrumento desde el espectro (M40 Deep Learning).
