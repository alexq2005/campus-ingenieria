🦯 Bastón Inteligente para Personas Ciegas

🌍 El problema: el bastón blanco tradicional es genial para el suelo, pero no detecta obstáculos a la altura del torso o la cabeza — una rama, un cartel, un camión estacionado, una puerta abierta. A quién ayuda: las ~40 millones de personas ciegas del mundo. Un complemento que avise de esos obstáculos con vibración mejora la seguridad sin reemplazar la técnica que ya dominan.
🎯 Objetivo: añadir al bastón sensores de ultrasonido que miden la distancia a obstáculos al frente y arriba, y avisan con vibración cuya intensidad/frecuencia crece al acercarse. Comunicación háptica: no usa la vista ni satura el oído (que la persona necesita para orientarse).
🙌 Principio de diseño: complementar, no reemplazar. El bastón tradicional y el oído son herramientas que la persona ya domina. Este dispositivo suma información, sin taparles el sonido del entorno ni exigir que confíen ciegamente en la electrónica.
🔗 Conexión con el campus: E05 Sensores y Actuadores (ultrasonido, motor de vibración), E03 (timing, bajo consumo), E06 (eco, tiempo de vuelo) y el P10 Robot Evita-Obstáculos (mismo sensor, otro fin).

Cómo funciona — eco que se vuelve vibración

Qué vas a aprender

  • Medir distancia con ultrasonido (tiempo de vuelo del eco) (E05/E06).
  • Diseño de retroalimentación háptica: mapear distancia a vibración de forma intuitiva.
  • Cubrir varias alturas (torso/cabeza) con más de un sensor.
  • Filtrar lecturas erráticas y evitar falsos avisos (E07).
  • Ergonomía y bajo consumo para uso diario real (E03).
  • Diseño centrado en el usuario: probar con personas ciegas.

Componentes

ESP32/Arduino + 1-2 sensores ultrasónicos HC-SR04 (o ToF láser VL53L0X) + motor de vibración (como el del celular) + batería pequeña · montaje liviano en el bastón. Opcional: buzzer para alertas distintas.

Código clave (distancia → vibración)

long distancia = medirUltrasonido();   // cm, por tiempo de vuelo (E06)

if (distancia < UMBRAL_MAX) {          // hay un obstáculo en rango
  // Más cerca → vibración más intensa y frecuente (mapeo intuitivo, E05)
  int intensidad = map(distancia, 5, UMBRAL_MAX, 255, 40);
  int pausa      = map(distancia, 5, UMBRAL_MAX, 80, 600);
  vibrar(intensidad);
  delay(pausa);
  vibrar(0);
  delay(pausa);
} else {
  vibrar(0);                           // camino libre → silencio háptico
}
🔗 El map() que convierte distancia en intensidad de vibración es diseño de interfaz no visual: igual que el robot del P10 usa el mismo sensor para decidir, acá lo usás para comunicar a un humano por el tacto. La elección del mapeo (lineal, exponencial, ritmo) es lo que hace la diferencia entre útil y molesto — eso se ajusta con usuarios reales.

Fases

Fase 1: medí distancia con el ultrasonido y mostrala por serial. Verificá el rango y el ruido.
Fase 2: manejá el motor de vibración con intensidad variable (PWM).
Fase 3: mapeá distancia → vibración. Probá distintos mapeos hasta que se sienta intuitivo.
Fase 4: filtrá lecturas erráticas, sumá un segundo sensor para la altura de la cabeza.
Fase 5: montaje liviano en el bastón, batería para un día, y prueba con un usuario (ojos vendados como mínimo).
✅ Terminado cuando:
  • Detecta obstáculos al frente y a la altura de la cabeza de forma confiable.
  • La vibración comunica la distancia de manera intuitiva (sin mirar ni explicación).
  • No genera falsos avisos constantes (filtrado correcto).
  • Es liviano, dura el día y no estorba la técnica del bastón tradicional.
  • Lo probaste con una persona y ajustaste según su feedback.

Variantes

  1. Detección de escalones/desniveles hacia abajo (sensor apuntando al piso).
  2. Distintos patrones de vibración para distintos tipos de obstáculo.
  3. Audio espacial opcional por hueso (no tapa el oído).
  4. Detección de cruces/semáforos con visión (M42) para una versión avanzada.
  5. Botón de emergencia que comparte ubicación a un contacto.
