💧 Monitor de Potabilidad del Agua

🌍 El problema: ~2.000 millones de personas usan agua contaminada con heces, y las enfermedades diarreicas matan a cientos de miles de niños por año. Muchas veces el agua parece limpia pero no lo es. A quién ayuda: comunidades rurales, escuelas y campamentos que necesitan saber, en el momento y sin laboratorio, si una fuente de agua es razonablemente segura para beber.
🎯 Objetivo: un medidor portátil que combina turbidez (qué tan turbia está), TDS (sólidos disueltos) y pH, y muestra un semáforo simple: verde / amarillo / rojo. No reemplaza un análisis de laboratorio, pero da una señal inmediata y entendible para tomar decisiones.
⚠️ Es un indicador, no un certificado de potabilidad. Turbidez/TDS/pH no detectan todos los patógenos ni metales pesados. Un "verde" no garantiza agua 100% segura; un "rojo" sí es una clara señal de alerta. Para consumo crítico, siempre hervir/filtrar y analizar en laboratorio.
🔗 Conexión con el campus: E05 Sensores (turbidez óptica, sondas), E03 (ADC, calibración), E00 (medición eléctrica) y P18 EDA (registro y tendencias).

Cómo funciona — tres medidas, un semáforo

Qué vas a aprender

  • Medir turbidez con un sensor óptico (cuánta luz dispersa el agua).
  • Medir TDS/conductividad y pH con sondas, y por qué importan.
  • Calibración con soluciones de referencia — clave para que el número signifique algo (E03).
  • Compensación por temperatura (afecta pH y conductividad).
  • Combinar varias medidas en un índice y un semáforo entendible.
  • Comunicar incertidumbre: qué SÍ y qué NO detecta el equipo.

Componentes

ESP32/Arduino + sensor de turbidez + sensor TDS (Gravity) + sonda de pH + sensor de temperatura (DS18B20) · pantalla OLED + LED RGB para el semáforo. Soluciones de calibración de pH (4.0 / 7.0).

Código clave (índice + semáforo)

// Cada medida cruda → unidad real, calibrada (E03)
float turbidez = leerTurbidez();      // NTU
float tds      = leerTDS(temp);       // ppm, compensado por temperatura
float ph       = leerPH();            // 0-14, calibrado con soluciones patrón

// Regla simple basada en guías de la OMS (educativa)
int estado;                            // 0 verde, 1 amarillo, 2 rojo
if (turbidez < 5 && tds < 600 && ph > 6.5 && ph < 8.5)
  estado = VERDE;                      // parámetros dentro de rango
else if (turbidez < 25 && tds < 1000)
  estado = AMARILLO;                   // dudoso: hervir/filtrar
else
  estado = ROJO;                       // claramente no apta

mostrarSemaforo(estado);
🔗 El corazón del proyecto es la calibración (E03): un sensor sin calibrar da números sin sentido. Medís soluciones patrón conocidas (pH 4.0 y 7.0) para mapear la lectura cruda del ADC a unidades reales. Sin ese paso, el "verde/rojo" sería puro adorno.

Fases

Fase 1: leé cada sensor crudo y entendé su salida. Probá con agua limpia y agua con tierra/sal.
Fase 2: calibrá pH y TDS con soluciones de referencia. Compensá por temperatura.
Fase 3: combiná las medidas en el índice y el semáforo verde/amarillo/rojo.
Fase 4: validá contra muestras conocidas (agua de red vs charco). ¿El semáforo acierta?
Fase 5: registro de mediciones (P18) y caja portátil resistente al agua.
✅ Terminado cuando:
  • Distingue claramente agua de red de agua visiblemente contaminada.
  • Los sensores están calibrados con patrones (no valores crudos).
  • El semáforo es entendible por cualquiera, sin saber de química.
  • La interfaz aclara qué NO detecta (patógenos, metales) y recomienda hervir ante la duda.
  • Es portátil y resiste el uso en campo.

Variantes

  1. Registro georreferenciado para mapear fuentes de agua de una región (con P04 calidad de aire = "mapa ambiental").
  2. Alerta automática a la comunidad cuando una fuente pasa a rojo.
  3. Medir cloro residual (clave tras potabilización).
  4. Modelo ML que estima riesgo combinando todas las variables (M39).
  5. Integrar con un sistema de filtrado que se active según la lectura (E08 control).
