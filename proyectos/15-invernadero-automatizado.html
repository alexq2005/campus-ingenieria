🌱 Invernadero Automatizado

🎯 Objetivo: un invernadero que mantiene solo sus condiciones ideales. Mide humedad del suelo, temperatura, humedad del aire y luz, y actúa: riega cuando el suelo se seca, ventila cuando hace calor, ilumina cuando falta luz. Es el control de lazo cerrado de E08 aplicado a algo vivo — medí, comparás con el objetivo, corregís.
🔗 Conexión con el campus: aplica E08 Control (lazo cerrado, histéresis), E05 (sensores y actuadores: bomba, ventilador, relés), E03 (ADC, GPIO) y E00 (manejo de cargas con relé).

Cómo funciona — un lazo cerrado por variable

Qué vas a aprender

  • Lazo cerrado y por qué la histéresis evita que el actuador "tabletee" (E08).
  • Leer sensores analógicos (humedad de suelo, LDR) con el ADC (E03).
  • Manejar cargas reales (bomba 12V, ventilador) con relés/MOSFET sin freír el micro (E00/E05).
  • Múltiples lazos independientes (riego, temperatura, luz) en un mismo loop.
  • Seguridad física: fusibles, aislar la lógica de la potencia, fail-safe.
  • Registrar datos y revisar el comportamiento del control en el tiempo.

Stack

ESP32 o Arduino · sensor de humedad de suelo (capacitivo) · DHT22 (temp/humedad aire) · LDR (luz) · módulo relé o MOSFET · bomba sumergible 5-12V · ventilador · tira LED de cultivo. Protoboard primero, después caja estanca.

Código clave (control con histéresis)

// Histéresis: dos umbrales evitan que la bomba se prenda/apague sin parar (E08)
const int OBJETIVO_BAJO = 55;   // % humedad: por debajo, regar
const int OBJETIVO_ALTO = 65;   // % humedad: por encima, cortar
bool regando = false;

void controlarRiego() {
  int humedad = leerHumedadSuelo();   // ADC 0-100% (E03)

  if (!regando && humedad < OBJETIVO_BAJO) {
    digitalWrite(BOMBA, HIGH);        // actuador ON (E05)
    regando = true;
  } else if (regando && humedad > OBJETIVO_ALTO) {
    digitalWrite(BOMBA, LOW);         // actuador OFF
    regando = false;
  }
  // entre 55% y 65% no hace nada: esa "zona muerta" da estabilidad
}
🔗 La histéresis (dos umbrales en vez de uno) es la misma idea del termostato on/off de E08. Con un solo umbral, el ruido del sensor haría que la bomba se prenda y apague decenas de veces por minuto — desgaste y oscilación. La zona muerta es el truco que lo estabiliza.

Fases

Fase 1: leé los 4 sensores y mostralos por serial. Calibrá el sensor de suelo (seco vs mojado).
Fase 2: un solo lazo: riego por histéresis. Probalo con una maceta real.
Fase 3: sumá los lazos de temperatura (ventilador) y luz (LED de cultivo).
Fase 4: registrá lecturas (SD o MQTT, conecta con P14) y graficá un día completo.
Fase 5: fail-safe: si un sensor da lectura imposible, apagá todo y avisá (no inundes la planta).
✅ Terminado cuando:
  • El invernadero mantiene la humedad del suelo en su rango sin que toques nada por días.
  • La bomba NO tabletea (la histéresis funciona).
  • La parte de potencia está aislada de la lógica (relé/optoacoplador), con fusible.
  • Tenés un registro que muestra cómo el control reacciona a las condiciones.
  • Si un sensor falla, el sistema entra en modo seguro en vez de hacer un desastre.

Variantes

  1. Pasar de histéresis a PID para temperatura (E08) — control fino del ventilador por PWM.
  2. Predicción de riego con un modelo simple según clima (M39 ML).
  3. Dashboard remoto vía MQTT + React (P14 + Curso-React).
  4. Energía solar + batería (gestión de energía, E00).
  5. Notificación al teléfono cuando el tanque de agua está vacío.
