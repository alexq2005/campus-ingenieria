🌊 Alerta Temprana de Inundaciones

🌍 El problema: las inundaciones repentinas (crecidas) son uno de los desastres más mortales, y muchas veces la diferencia entre evacuar a tiempo o no es de minutos. Las cuencas pequeñas rara vez tienen monitoreo oficial. A quién ayuda: comunidades río abajo, escuelas y centros de salud en zonas inundables — un sensor aguas arriba que avisa cuando el río crece da el tiempo de oro para ponerse a salvo.
🎯 Objetivo: sensores que miden el nivel del agua en un punto del río aguas arriba y, al superar umbrales, disparan una alerta escalonada (precaución → evacuar) a la comunidad por sirena local, SMS y/o radio LoRa. Robusto, autónomo y confiable justo cuando el clima está peor.
🔗 Conexión con el campus: E05 Sensores (nivel, ultrasonido), E08 (umbrales, histéresis, tendencia), M15 Redes (LoRa/GSM, redundancia) y el proyecto de incendios (misma arquitectura).

Cómo funciona — aguas arriba avisa a aguas abajo

Qué vas a aprender

  • Medir nivel de agua (ultrasonido sin contacto, o sondas) (E05).
  • Detectar no solo el nivel sino la velocidad de subida (tendencia → crecida rápida) (E08).
  • Alertas escalonadas con histéresis para no oscilar entre estados.
  • Comunicación redundante (LoRa + GSM): la alerta DEBE llegar (M15).
  • Energía autónoma y resistencia a la intemperie extrema.
  • Diseño fail-safe: ante la duda o falla, alertar (mejor falsa alarma que muerte).

Componentes

ESP32 + sensor de nivel (ultrasónico montado sobre el agua, o sonda de presión) · LoRa + módulo GSM (redundancia) · sirena/baliza local · panel solar + batería · caja estanca. Punto de medición elevado y protegido.

Código clave (nivel + tendencia + alerta escalonada)

float nivel = medirNivel();                 // m sobre el cauce (E05)
float subida = (nivel - nivelAnterior) / dt; // velocidad de crecida (E08)
nivelAnterior = nivel;

// Alerta escalonada: nivel ALTO o subida MUY rápida disparan evacuación
if (nivel > NIVEL_EVACUAR || subida > SUBIDA_PELIGRO) {
  alertar(EVACUAR);          // sirena + SMS + LoRa, redundante (M15)
} else if (nivel > NIVEL_PRECAUCION) {
  alertar(PRECAUCION);
} else {
  alertar(NORMAL);
}
// La tendencia importa: 50 cm de subida en 5 min es más grave que 1 m estable
🔗 La clave no es solo el nivel, sino la derivada (velocidad de subida) — exactamente el término D del control de E08. Una crecida repentina se ve en la tasa de cambio antes que en el valor absoluto. Y la redundancia de comunicación (M15) es vida o muerte: si falla un canal, el otro debe llevar la alerta.

Fases

Fase 1: medí nivel de agua de forma confiable (probá en un recipiente, luego en un arroyo seguro).
Fase 2: calculá la tendencia (velocidad de subida) y definí umbrales escalonados.
Fase 3: alerta local (sirena/baliza) + envío por LoRa o GSM. Probá el alcance.
Fase 4: redundancia y fail-safe: ¿qué pasa si se corta la energía o un canal? Debe seguir alertando.
Fase 5: autonomía solar, caja estanca, y un protocolo claro de qué hace la comunidad ante cada nivel.
✅ Terminado cuando:
  • Detecta una subida de nivel y dispara la alerta correcta (precaución/evacuar).
  • Usa la tendencia, no solo el valor instantáneo.
  • La alerta llega por al menos dos canales (redundancia).
  • Funciona autónomo con energía solar y resiste a la intemperie.
  • Ante falla, el sistema peca de precavido (fail-safe hacia la alerta).

Variantes

  1. Red de varios sensores a lo largo de la cuenca para estimar la propagación.
  2. Mapa público en vivo con el nivel de cada punto (P14 MQTT + React).
  3. Modelo que predice el pico de la crecida con datos de lluvia (M39).
  4. Misma plataforma para deslizamientos de tierra (inclinómetro).
  5. Integración con autoridades de protección civil.
