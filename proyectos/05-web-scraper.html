Proyecto 05 Intermedio ⏱ ~1 semana Python + pandas

🕷️ Web Scraper + Análisis

🎯 Objetivo: un script que extrae datos de una web (precios, noticias, listados), los limpia, los guarda en CSV/JSON y genera estadísticas y gráficos. Automatización real: lo programás para que corra solo y te junte datos mientras dormís. Es la puerta de entrada al mundo de los datos.
🔗 Conexión con el campus: Python I/O (requests, archivos, JSON/CSV), estructuras de datos, Linux cron (correrlo programado) y el P18 EDA (analizar lo que juntaste).

Cómo funciona — del HTML al dato limpio

Qué vas a aprender

  • Hacer pedidos HTTP con requests y entender el HTML que vuelve.
  • Parsear y extraer datos con BeautifulSoup (selectores, etiquetas, atributos).
  • Limpiar datos del mundo real: precios con símbolos, fechas en formatos varios, nulos.
  • Persistir en CSV/JSON y leerlos de vuelta (Python I/O).
  • Analizar con pandas: tendencias, máximos, promedios, gráficos.
  • Automatizar con cron (Linux) para que junte datos solo, cada día.
  • Scraping ético: respetar robots.txt, no sobrecargar el servidor, usar APIs cuando existan.

Stack

Python · requests + BeautifulSoup (o Playwright si la web carga con JS) · pandas + matplotlib · cron (Linux) para programarlo. Datasets sugeridos: precios de un e-commerce, noticias, clima, listados públicos.

Código clave (scrapear + guardar)

import requests, csv, time
from bs4 import BeautifulSoup

def scrapear(url):
    # 1) Pedir la página (con User-Agent y pausa: scraping ético)
    r = requests.get(url, headers={"User-Agent": "MiBot/1.0"}, timeout=10)
    r.raise_for_status()
    soup = BeautifulSoup(r.text, "html.parser")

    # 2) Extraer SOLO lo que importa (ej: productos)
    items = []
    for card in soup.select(".producto"):
        nombre = card.select_one(".nombre").get_text(strip=True)
        precio_txt = card.select_one(".precio").get_text(strip=True)
        precio = float(precio_txt.replace("$", "").replace(".", "").replace(",", "."))  # limpieza
        items.append({"nombre": nombre, "precio": precio})
    return items

# 3) Guardar en CSV (Python I/O — ojo el encoding en Windows: utf-8 explícito)
datos = scrapear("https://ejemplo.com/productos")
with open("productos.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.DictWriter(f, fieldnames=["nombre", "precio"])
    w.writeheader(); w.writerows(datos)
    time.sleep(2)   # no martillar el servidor
🔗 El precio.replace(...) es el corazón del scraping: los datos web vienen sucios ("$1.299,00") y hay que convertirlos a número. Y el encoding="utf-8" explícito evita el clásico bug de Windows (cp1252) con acentos — la misma trampa de boundary que aparece una y otra vez al cruzar datos entre sistemas.

Fases

Fase 1: bajá UNA página con requests e imprimila. Entendé su estructura HTML (usá las DevTools del navegador).
Fase 2: extraé un dato (un precio, un título) con BeautifulSoup. Después, todos los de la página.
Fase 3: limpieza + guardado en CSV/JSON. Manejá los casos rotos (precio faltante, formato raro).
Fase 4: paginá (varias páginas) y analizá con pandas: ¿cuál es el más barato? ¿cómo cambió el precio?
Fase 5: programalo con cron para que corra cada día y compare precios en el tiempo (detección de bajadas).
✅ Terminado cuando:
  • Extraés datos de varias páginas y los guardás limpios en CSV/JSON.
  • El script maneja errores (página caída, dato faltante) sin romperse.
  • Generás al menos una estadística y un gráfico con pandas.
  • Respetás robots.txt y ponés pausas (scraping ético, no DoS).
  • Corre solo con cron y acumula histórico día a día.
⚠️ Scraping responsable: revisá los términos de uso y el robots.txt del sitio. Poné pausas entre pedidos (no sobrecargues el servidor). Si hay una API oficial, usala antes que scrapear. Scrapear datos personales o con copyright para revenderlos puede ser ilegal.

Variantes

  1. Alertas: avisarte por mail/Telegram cuando un precio baja de un umbral.
  2. Webs con JavaScript: usar Playwright/Selenium en vez de requests.
  3. Dashboard en vivo de los datos (conecta con P18 EDA y React).
  4. Monitor de precios de competencia (la base del negocio de datos — ver Licitá).
  5. Pipeline de datos: scraper → base de datos (P23) → API → frontend.
