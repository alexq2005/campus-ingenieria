🛰️ Escáner de Puertos

🎯 Objetivo: una herramienta que descubre qué puertos están abiertos en un host y qué servicio corre en cada uno. Vas a entender cómo funcionan los sockets TCP por dentro, por qué la concurrencia lo hace 100× más rápido, y cómo un atacante (y un defensor) ve tu red.
⚠️ Solo escaneá redes/hosts que te pertenezcan o tengas permiso explícito de escanear. Escanear sistemas ajenos es ilegal en muchos países. Practicá contra localhost, tu propio router, o laboratorios diseñados para eso (Metasploitable, TryHackMe).
🔗 Conexión con el campus: M30 Seguridad de Redes (puertos, servicios, defensa), M15 Redes (TCP, three-way handshake), Python concurrencia (threads, async) y Linux redes (ss, netstat).

Cómo funciona — el handshake que delata el puerto

Qué vas a aprender

  • Cómo funciona un socket TCP y el three-way handshake (M15).
  • Qué revela un puerto abierto: el servicio y a veces su versión (banner grabbing).
  • Por qué la concurrencia (threads/async) es clave: 65.535 puertos en serie es eternо.
  • Diferencia entre puerto cerrado y filtrado (firewall).
  • La perspectiva defensiva: cerrar puertos, fail2ban, mínima superficie (M30).
  • Timeouts y manejo de errores de red robusto.

Stack

Python · módulo socket (estándar) · concurrent.futures o asyncio para concurrencia · comparalo con nmap real. Practicá contra 127.0.0.1 y tu router.

Código clave (escaneo concurrente)

import socket
from concurrent.futures import ThreadPoolExecutor

def escanear_puerto(host, puerto, timeout=1.0):
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(timeout)
        if s.connect_ex((host, puerto)) == 0:    # 0 = handshake OK = abierto
            try:
                banner = s.recv(1024).decode(errors="ignore").strip()
            except Exception:
                banner = ""
            return puerto, banner
    return None

def escanear(host, puertos):
    # Concurrencia (M Python 11): cientos de puertos a la vez, no en fila
    with ThreadPoolExecutor(max_workers=200) as pool:
        resultados = pool.map(lambda p: escanear_puerto(host, p), puertos)
    return [r for r in resultados if r]           # solo los abiertos
🔗 connect_ex hace el handshake de M15 y devuelve 0 si el puerto acepta. El ThreadPoolExecutor es concurrencia de Python (M11): como escanear es I/O-bound (esperás respuesta de red), los threads se solapan y el escaneo pasa de minutos a segundos. La elección threads vs async es la misma discusión de M11.

Fases

Fase 1: escaneá UN puerto de localhost. Entendé connect_ex y los timeouts.
Fase 2: escaneá un rango (1-1024) en serie. Cronometralo — vas a sufrir la lentitud.
Fase 3: agregá concurrencia. Medí el speedup (debería ser enorme).
Fase 4: banner grabbing: identificá el servicio (SSH, HTTP) y su versión.
Fase 5: reporte claro (puerto / servicio / estado) y compará tus resultados con nmap.
✅ Terminado cuando:
  • Escaneás los 1024 puertos bien conocidos de localhost en segundos.
  • Identificás al menos un servicio por su banner.
  • Distinguís cerrado de filtrado y manejás timeouts sin crashear.
  • Tus resultados coinciden con nmap en el mismo host.
  • Entendés y podés explicar el lado defensivo (qué cerrarías y por qué).

Variantes

  1. Versión async con asyncio y compará con threads (M11).
  2. Descubrimiento de hosts en la LAN (ping sweep) antes de escanear.
  3. Detección de servicios vulnerables conocidos (cruzar versión con CVEs).
  4. Modo defensivo: un mini-IDS que detecta cuando ALGUIEN te escanea (conecta con análisis de logs).
  5. Exportá a JSON e integralo con un dashboard (P18 / P23).
