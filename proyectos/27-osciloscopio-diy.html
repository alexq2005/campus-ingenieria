📟 Osciloscopio DIY

🎯 Objetivo: construir un osciloscopio casero —un instrumento que dibuja cómo cambia un voltaje en el tiempo— con un microcontrolador que muestrea rápido por su ADC y manda los datos a una pantalla o al navegador. Vas a ver las señales que estudiás en teoría: una onda, el rebote de un botón, el PWM de un motor. Es el instrumento que todo el que toca electrónica termina queriendo.
🔗 Conexión con el campus: E06 Señales (muestreo, Nyquist, dominio tiempo), E07 DSP (FFT, filtros, trigger), E03 (ADC rápido) y el Vúmetro con FFT (P12) — comparten el motor de DSP.

Cómo funciona — de voltaje a dibujo

Qué vas a aprender

  • Muestreo y Nyquist: por qué la frecuencia de muestreo limita lo que podés ver (E06).
  • Leer el ADC rápido (DMA) sin que el micro se cuelgue (E03).
  • El trigger: estabilizar una onda repetitiva para que no "viaje" (E07).
  • Dibujar la forma de onda (en OLED, TFT o canvas del navegador).
  • Escalas de tiempo/voltaje y medir frecuencia/amplitud.
  • Opcional: FFT en vivo (el espectro, como el Vúmetro P12).

Componentes

ESP32 (ADC + WiFi para ver en el navegador) o un micro con ADC rápido · divisor resistivo / acondicionamiento de entrada (proteger el pin) · pantalla OLED/TFT, o servir la onda por WebSocket a una página. ⚠️ Solo señales de baja tensión y seguras.

Código clave (muestrear + trigger)

uint16_t buffer[N];

void capturar() {
  for (int i = 0; i < N; i++) {
    buffer[i] = analogRead(PIN);          // muestrea (E03)
    delayMicroseconds(US_ENTRE_MUESTRAS); // define la base de tiempo (E06)
  }
}

// Trigger: arrancar a dibujar cuando la señal cruza un umbral subiendo
int encontrarTrigger() {
  for (int i = 1; i < N; i++)
    if (buffer[i-1] < UMBRAL && buffer[i] >= UMBRAL)  // cruce ascendente (E07)
      return i;        // dibujar desde acá → la onda se ve QUIETA
  return 0;
}
🔗 El trigger es la diferencia entre una onda ilegible que tiembla y una imagen estable: en vez de dibujar desde un punto cualquiera, arrancás siempre en el mismo lugar de la onda (un cruce por umbral). Es DSP puro (E07). Y la separación entre muestras define tu "base de tiempo": muy lento y te perdés los detalles rápidos (violás Nyquist, E06); muy rápido y ves poco intervalo.

Fases

Fase 1: leé el ADC y mandá los valores por serial. Graficalos con el Serial Plotter.
Fase 2: buffer + dibujo en pantalla/navegador. Ya tenés un "osciloscopio" básico.
Fase 3: trigger por umbral: que una onda repetitiva se vea quieta.
Fase 4: controles: base de tiempo, escala de voltaje, medir frecuencia/amplitud.
Fase 5: modo FFT (espectro) reutilizando el motor del Vúmetro (P12).
✅ Terminado cuando:
  • Mostrás una onda real (un generador, el PWM de un pin, un audio) de forma estable.
  • El trigger mantiene la onda quieta en vez de viajar.
  • Podés medir su frecuencia y amplitud aproximadas.
  • Entendés y respetás Nyquist (no "inventás" señales que no podés muestrear).
  • La entrada está protegida (no le metés tensión peligrosa al pin).

Variantes

  1. Dos canales (comparar dos señales).
  2. Analizador lógico (señales digitales, protocolos I2C/SPI).
  3. Generador de funciones integrado (sacás una onda por DAC/PWM y la medís).
  4. Captura y exportá la onda como CSV para analizar (P18 EDA).
  5. Interfaz web completa con WebSocket en vivo (Curso-React).
