🆘 Detector de Caídas para Adultos Mayores

🌍 El problema: las caídas son la segunda causa mundial de muerte por lesiones no intencionales (OMS). Para un adulto mayor que vive solo, el peligro no es solo la caída: es quedar horas en el suelo sin poder pedir ayuda. A quién ayuda: personas mayores que viven solas y sus familias — un aviso en segundos puede ser la diferencia entre un susto y una tragedia.
🎯 Objetivo: una pulsera o colgante con un acelerómetro que distingue una caída real de los movimientos normales (sentarse, agacharse) usando ML, y al detectarla envía una alerta automática a un familiar con la ubicación. Con un botón de pánico manual y confirmación para evitar falsas alarmas.
🔗 Conexión con el campus: E05 Sensores (acelerómetro/IMU), E07 DSP (filtrar la señal, magnitud), M39 ML (clasificar caída vs no-caída) y M15 Redes (la alerta).

Cómo funciona — la firma de una caída

Qué vas a aprender

  • Leer un acelerómetro/IMU de 3 ejes y calcular la magnitud (E05).
  • Filtrar y extraer features de la señal: caída libre, pico de impacto, varianza (E07).
  • Entrenar un clasificador (umbral inteligente o ML) caída vs actividad normal (M39).
  • Minimizar falsos positivos (sentarse fuerte ≠ caída) y falsos negativos.
  • Enviar una alerta (WiFi/GSM) con confirmación y botón de pánico.
  • Diseño para personas mayores: simple, autónomo, batería de días.

Componentes

ESP32 + acelerómetro MPU6050 o ADXL345 · batería LiPo pequeña · botón · buzzer/vibrador para la cuenta regresiva de cancelación · módulo WiFi (incluido) o SIM800 para zonas sin WiFi. Empezá registrando datos reales de movimientos.

Código clave (la detección)

// Detección por máquina de estados sobre la magnitud de aceleración (E07)
float mag = sqrt(ax*ax + ay*ay + az*az);   // magnitud 3D

switch (estado) {
  case NORMAL:
    if (mag < UMBRAL_CAIDA_LIBRE)          // 1. casi 0g → posible caída libre
      estado = CAIDA_LIBRE;
    break;
  case CAIDA_LIBRE:
    if (mag > UMBRAL_IMPACTO)              // 2. pico fuerte → impacto
      { estado = IMPACTO; t_impacto = millis(); }
    break;
  case IMPACTO:
    if (esQuietud(mag) && millis() - t_impacto > 3000)  // 3. quieto 3s
      alertar();                          // → avisar a la familia
    break;
}
🔗 Esto es una máquina de estados (como el semáforo del P09) sobre features de la señal (E07). La secuencia caída-libre → impacto → quietud es la clave: un solo umbral de "golpe" daría falsas alarmas todo el día. Con ML (M39) en vez de umbrales fijos, el detector aprende la diferencia de datos reales.

Fases

Fase 1: registrá aceleración de 3 ejes durante actividades normales y caídas simuladas (sobre un colchón). Graficá las firmas.
Fase 2: detección por máquina de estados con umbrales. Medí falsos positivos/negativos.
Fase 3: mejorá con un clasificador ML entrenado con tus datos (M39). Compará.
Fase 4: cuenta regresiva cancelable (buzzer + botón) antes de alertar — evita falsas alarmas.
Fase 5: alerta real: mensaje al familiar con hora y ubicación. Autonomía de batería de varios días.
✅ Terminado cuando:
  • Detecta caídas simuladas de forma confiable y NO se dispara con actividad normal.
  • Da una ventana para cancelar antes de alertar (botón + buzzer).
  • La alerta llega a un contacto con la hora del evento.
  • La batería dura días, no horas (es un wearable de uso continuo).
  • Reportás tasas reales de falsos positivos/negativos con datos.
⚠️ Es un sistema de apoyo, no un dispositivo médico certificado. No reemplaza supervisión profesional. Para uso real se necesita validación clínica y redundancia. Aquí el valor es entender cómo se construye y por qué importa la baja tasa de falsas alarmas.

Variantes

  1. Monitoreo de signos vitales (ritmo cardíaco) integrado — conecta con el Oxímetro.
  2. Detección de inactividad anómala (no se movió en todo el día).
  3. Red de varios wearables reportando a un panel de cuidador.
  4. TinyML: correr el modelo en el propio chip sin enviar datos crudos (privacidad).
  5. Recordatorios de medicación con confirmación.
