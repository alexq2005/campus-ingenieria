Módulo 04 — Análisis Exploratorio (EDA)

Ya cargaste los datos (M02) y los limpiaste (M03). Ahora viene la parte detectivesca: conocerlos. El Análisis Exploratorio de Datos (EDA, por Exploratory Data Analysis) es el paso donde dejás que los datos te cuenten su historia antes de meter un solo modelo.

💡 EDA = conocer los datos antes de modelar. No estás prediciendo nada todavía; estás haciéndole preguntas a la tabla: ¿qué distribución tiene cada variable? ¿qué se relaciona con qué? ¿hay patrones o grupos que saltan a la vista? Si te saltás esto, vas a modelar a ciegas y te vas a sorprender (mal) después.

Un buen EDA te ahorra horas de modelado inútil: descubrís qué columnas importan, cuáles están correlacionadas, cuáles tienen valores raros y qué hipótesis vale la pena probar.

Variables categóricas: value_counts()

Cuando una columna tiene categorías (ciudad, producto, sí/no), lo primero es contar cuántas veces aparece cada valor. Para eso está value_counts():

import pandas as pd

df = pd.read_csv("ventas.csv")

# ¿Cuántas filas hay de cada categoría?
df["categoria"].value_counts()
# Electronica    412
# Hogar          318
# Ropa           205
# Juguetes        65

# Como proporción (suma 1.0) en vez de conteo absoluto
df["categoria"].value_counts(normalize=True)

# Incluir los nulos en el conteo
df["categoria"].value_counts(dropna=False)
🔧 value_counts() ordena de mayor a menor por defecto. Con normalize=True ves porcentajes, ideal para detectar clases desbalanceadas (ej: el 95% de las filas son una sola categoría — eso afecta cómo modelás después).

groupby + agg: resúmenes por grupo

La operación más poderosa del EDA: partir los datos en grupos y calcular una estadística por grupo. El patrón mental es split → apply → combine (separar por grupo, aplicar una función, recombinar el resultado).

# Promedio de 'valor' por cada categoria
df.groupby("categoria")["valor"].mean()

# Suma total vendida por categoria
df.groupby("categoria")["valor"].sum()

# Cantidad de filas por categoria (igual que value_counts)
df.groupby("categoria")["valor"].count()

Con .agg() calculás varias estadísticas de una sola pasada — mucho más legible que llamar a cada una por separado:

# Varias métricas a la vez sobre 'valor', agrupando por categoria
df.groupby("categoria")["valor"].agg(["mean", "median", "min", "max", "count"])
#               mean  median  min   max  count
# categoria
# Electronica  340.2   299.0   12  1850    412
# Hogar        128.7   110.0    5   980    318
# Ropa          74.3    65.0    3   420    205
# Juguetes      41.9    38.0    2   180     65

# Agrupar por DOS columnas a la vez
df.groupby(["categoria", "region"])["valor"].mean()
El resultado de groupby tiene la columna agrupada como índice. Si querés que vuelva a ser una columna normal, encadená .reset_index(). Esto es clave cuando después querés graficar (M05) o hacer un merge.

Tablas cruzadas: pivot_table y crosstab

Cuando querés ver dos dimensiones a la vez (filas × columnas), las tablas cruzadas son la herramienta. Una pivot_table reorganiza los datos en una grilla y agrega los valores:

# Promedio de 'valor' con categoria en filas y region en columnas
df.pivot_table(
    values="valor",
    index="categoria",
    columns="region",
    aggfunc="mean"
)
# region        Norte    Sur   Este
# categoria
# Electronica   355.1  320.4  340.9
# Hogar         130.2  118.6  135.0
# Ropa           70.5   78.2   72.1

crosstab es un atajo cuando solo querés contar cuántas filas caen en cada cruce de categorías:

# ¿Cuántas filas hay por cada combinación categoria × region?
pd.crosstab(df["categoria"], df["region"])
# region       Norte  Sur  Este
# categoria
# Electronica    180  120   112
# Hogar          140   98    80
# Ropa            85   70    50

# Con proporciones por fila (cada fila suma 1.0)
pd.crosstab(df["categoria"], df["region"], normalize="index")
🔍 Una pivot_table es la tabla dinámica de Excel, pero en código y reproducible. index son las filas, columns las columnas, values lo que se agrega y aggfunc cómo se agrega (promedio, suma, conteo...).

Correlación: df.corr()

La correlación mide qué tan relacionadas están dos variables numéricas. df.corr() calcula la matriz de correlación de Pearson: un número entre -1 y 1 para cada par de columnas numéricas.

# Matriz de correlación de todas las columnas numéricas
df.corr(numeric_only=True)
#              precio  cantidad  descuento  satisfaccion
# precio        1.00     -0.62       0.31         -0.08
# cantidad     -0.62      1.00      -0.18          0.05
# descuento     0.31     -0.18       1.00          0.44
# satisfaccion -0.08      0.05       0.44          1.00
Valor de correlaciónQué significaEjemplo
+1.0Relación positiva perfecta (suben juntas)Una variable es 2× la otra
+0.6Positiva fuerteA más descuento, más satisfacción
~0.0Sin relación linealPrecio y satisfacción (-0.08)
-0.6Negativa fuerte (una sube, la otra baja)A más precio, menos cantidad vendida
-1.0Relación negativa perfectaInversamente proporcionales

En el ejemplo de arriba: precio y cantidad tienen -0.62 → cuanto más caro, menos se vende (relación negativa fuerte, tiene sentido). descuento y satisfaccion tienen +0.44 → más descuento se asocia a clientes más contentos (positiva moderada).

La diagonal de la matriz siempre es 1.00 (cada columna correlaciona perfecto consigo misma) y es simétrica: corr(A,B) es igual a corr(B,A). Pearson solo captura relaciones lineales: una relación en forma de U puede dar correlación ~0 aunque las variables estén fuertemente relacionadas.

Resumen estadístico: describe()

describe() es tu radar inicial: de un vistazo ves la distribución de cada columna numérica y detectás columnas clave o valores sospechosos.

df.describe()
#         precio  cantidad  satisfaccion
# count   1000.0    1000.0        1000.0
# mean     185.4       3.2           7.8
# std      142.1       2.1           1.4
# min        2.0       1.0           1.0
# 25%       80.0       2.0           7.0
# 50%      150.0       3.0           8.0      <- la mediana
# 75%      255.0       4.0           9.0
# max     1850.0      15.0          10.0

# Para columnas de texto/categóricas
df.describe(include="object")

Mirá la distancia entre mean (185) y 50% (mediana, 150): cuando la media es bastante mayor que la mediana, hay valores altos tirando del promedio (distribución sesgada a la derecha). Eso solo lo ves comparando media vs mediana, no con la media sola.

Las trampas del EDA

📌 Correlación NO es causalidad. Que dos variables se muevan juntas no significa que una cause la otra. Las ventas de helado y los ahogamientos correlacionan fuerte... porque ambos suben en verano (el calor es la causa oculta). La correlación es una pista para investigar, nunca una conclusión.
Sacar conclusiones de muestras chicas. Si una categoría tiene 6 filas y otra 4000, el "promedio" de la de 6 es ruido. Siempre mirá el count de cada grupo antes de comparar promedios.
Mirar solo la media. Dos columnas pueden tener la misma media y distribuciones totalmente distintas (una concentrada, otra con outliers extremos). Siempre mirá la distribución completa (mediana, std, min, max), no solo el promedio.
Confiar en una correlación de Pearson para relaciones no lineales. Pearson solo ve líneas rectas. Una relación curva real puede aparecer como correlación ≈ 0 y hacerte descartar una variable importante.

Ejemplo completo: groupby + correlación

Juntemos las dos herramientas centrales sobre un mismo dataset y leamos los resultados como lo haría un analista:

import pandas as pd

df = pd.read_csv("ventas.csv")

# 1) Promedios por categoria — ¿qué categoria deja más por venta?
resumen = df.groupby("categoria")["precio"].agg(["mean", "count"])
print(resumen)
#               mean  count
# categoria
# Electronica  340.2    412   <- ticket alto, mucho volumen
# Hogar        128.7    318
# Ropa          74.3    205
# Juguetes      41.9     65   <- ojo: solo 65 filas, promedio menos confiable

# 2) Matriz de correlación de las variables numéricas
print(df.corr(numeric_only=True)["precio"].sort_values())
# cantidad      -0.62   <- a mayor precio, menor cantidad vendida
# satisfaccion  -0.08   <- precio casi no afecta la satisfaccion
# descuento      0.31
# precio         1.00

Interpretación: Electrónica es la categoría más valiosa (ticket alto + alto volumen). El precio y la cantidad están negativamente correlacionados (-0.62): subir precios reduce unidades vendidas — algo a tener en cuenta. La satisfacción casi no depende del precio (-0.08). Y cuidado con Juguetes: con solo 65 filas, su promedio es menos confiable que el de las demás.

El flujo de EDA en la práctica: (1) describe() para el panorama general → (2) value_counts() en las categóricas → (3) groupby + agg para resúmenes por grupo → (4) corr() para ver qué se relaciona con qué → (5) anotar hipótesis para confirmar visualizando (M05) y, eventualmente, modelando.
El EDA es iterativo: una correlación que encontrás te lleva a un groupby nuevo, que revela un grupo raro, que te manda de vuelta a la limpieza (M03). No es una checklist lineal; es una conversación con los datos.

Puente al M05: visualizar lo que encontraste

Todo lo que descubriste en este módulo —distribuciones, grupos, correlaciones— se comunica visualizando. Una matriz de correlación se entiende muchísimo mejor como un heatmap; un groupby de promedios, como un gráfico de barras; una distribución, como un histograma. En el M05 vas a aprender a convertir estas tablas en gráficos que cuentan la historia de un vistazo.

Checkpoint — ¿lo tenés claro?

¿Qué hace df.groupby("categoria")["valor"].mean()?

Separa las filas por cada valor de categoria, calcula el promedio de la columna valor dentro de cada grupo y devuelve una Serie con una entrada por categoría. Es el patrón split → apply → combine.

Una correlación de -0.62 entre precio y cantidad, ¿qué significa?

Una relación lineal negativa fuerte: cuando el precio sube, la cantidad vendida tiende a bajar (y viceversa). El signo indica la dirección y el valor absoluto (0.62) la fuerza. Pero ojo: indica asociación, no que el precio cause la caída de ventas.

¿Por qué no alcanza con mirar la media de una columna?

Porque dos columnas con la misma media pueden tener distribuciones muy distintas. La media se deja "tirar" por valores extremos; comparándola con la mediana (50%) detectás sesgo, y con std/min/max ves la dispersión real. Siempre mirá la distribución, no solo el promedio.

🧠 Autoevaluación

1. ¿Para qué sirve df["categoria"].value_counts()?

value_counts() cuenta las apariciones de cada valor único, ordenadas de mayor a menor. Con normalize=True devuelve proporciones en vez de conteos.

2. Una correlación de Pearson de +0.85 entre dos columnas indica que...

+0.85 es una relación lineal positiva fuerte: cuando una sube, la otra tiende a subir. Pero correlación NO es causalidad — solo indica asociación, no que una cause a la otra.

3. ¿Cuál de estas es una trampa típica del EDA que hay que evitar?

Comparar el promedio de un grupo de 6 filas con uno de 4000 es engañoso: el promedio de muestras chicas es ruido. Siempre mirá el count de cada grupo antes de sacar conclusiones.
