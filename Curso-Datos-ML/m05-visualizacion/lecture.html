Módulo 05 — Visualización

En el M04 exploraste los datos con números: medias, groupby, correlaciones. Ahora les vas a poner cara. Un gráfico bien hecho cuenta en un segundo lo que una tabla de cien filas esconde. Visualizar no es decorar: es pensar con los ojos.

¿Por qué visualizar? El cuarteto de Anscombe

💡 Una tabla resume; un gráfico revela. Cuando mirás df.describe() ves promedios y desvíos, pero no ves la forma de los datos: si hay dos grupos separados, una curva, un outlier que arruina todo. Esos patrones aparecen recién cuando dibujás.

El ejemplo clásico es el cuarteto de Anscombe: cuatro datasets distintos que tienen exactamente la misma media, la misma varianza, la misma correlación y la misma recta de regresión. Por las estadísticas, parecen idénticos. Pero al graficarlos, uno es una recta, otro una parábola, otro tiene un outlier brutal y otro casi no varía en X. La moraleja:

📌 Nunca confíes solo en los números resumen. Siempre graficá los datos antes de sacar conclusiones. Estadísticas iguales pueden esconder realidades completamente distintas.

matplotlib — la base de todo

matplotlib es la librería madre de los gráficos en Python. Es de bajo nivel (controlás todo a mano), un poco fea por defecto, pero está en todos lados. La convención universal es importar su submódulo pyplot como plt:

import matplotlib.pyplot as plt

# plot: línea (evolución / tendencia)
plt.plot([1, 2, 3, 4], [10, 8, 12, 15])
plt.show()

Los cuatro gráficos que más vas a usar de matplotlib:

plt.plot(x, y)        # línea: evolución temporal
plt.bar(cats, vals)   # barras: comparar categorías
plt.hist(serie)       # histograma: distribución de UNA variable
plt.scatter(x, y)     # dispersión: relación entre DOS variables
Un gráfico sin contexto no comunica. Siempre poné título y etiquetas de ejes. Cuando hay varias series, agregá leyenda: 
plt.scatter(df["altura"], df["peso"], label="personas")
plt.title("Peso vs. altura")
plt.xlabel("Altura (cm)")
plt.ylabel("Peso (kg)")
plt.legend()
plt.show()

Varios gráficos juntos: plt.subplots

Para mostrar varios gráficos en una misma figura usás plt.subplots(filas, columnas). Te devuelve la figura y un arreglo de ejes (ax); dibujás sobre cada uno por separado:

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].hist(df["edad"])
axes[0].set_title("Distribución de edad")

axes[1].scatter(df["altura"], df["peso"])
axes[1].set_title("Peso vs. altura")

fig.tight_layout()   # acomoda los espacios para que no se pisen
plt.show()
Ojo con la diferencia: en el modo rápido usás plt.title(), plt.xlabel(). Cuando trabajás con un objeto ax (subplots) los métodos llevan set_ adelante: ax.set_title(), ax.set_xlabel(). Es la misma idea, distinto nivel.

seaborn — más lindo y más estadístico

seaborn está construido encima de matplotlib. Hace dos cosas que matplotlib no: gráficos hermosos por defecto y funciones pensadas para estadística (te calcula la matriz de correlación, te dibuja los outliers de un boxplot, etc.). La convención es importarlo como sns:

import seaborn as sns
import matplotlib.pyplot as plt

sns.histplot(data=df, x="edad")        # histograma (distribución)
sns.boxplot(data=df, x="grupo", y="sueldo")   # caja + outliers por grupo
sns.scatterplot(data=df, x="altura", y="peso", hue="sexo")  # color por categoría
plt.show()
🎨 matplotlib es el motor; seaborn es la carrocería. seaborn no reemplaza a matplotlib: lo llama por debajo. Por eso seguís usando plt.show(), plt.title() y los ax de matplotlib para retocar lo que seaborn dibuja.

Las dos estrellas de seaborn: heatmap y pairplot

El heatmap pinta una matriz con colores. Su uso más común es la matriz de correlación (que viste en M04): de un vistazo ves qué variables se mueven juntas (rojo/azul fuerte) y cuáles no (cerca de 0).

corr = df.corr(numeric_only=True)   # matriz de correlación
sns.heatmap(corr, annot=True, cmap="coolwarm", vmin=-1, vmax=1)
plt.title("Matriz de correlación")
plt.show()

El pairplot dibuja, de un solo comando, todos los scatter de cada par de variables numéricas (y los histogramas en la diagonal). Es la herramienta más rápida para "ver todo el dataset de golpe":

sns.pairplot(df, hue="especie")   # hue colorea por categoría
plt.show()

Errores típicos al graficar

Gráficos sin título ni labels. El que lo mira (incluido vos en tres meses) no sabe qué representan los ejes ni de qué se trata. Título + xlabel + ylabel siempre.
Pie chart con muchas categorías. El ojo humano compara mal los ángulos. Con más de 3-4 porciones, una barra ordenada comunica mucho mejor.
Ejes truncados que engañan. Empezar el eje Y en 95 en vez de 0 hace que una diferencia minúscula parezca enorme. Es la trampa visual más común en la prensa.
Demasiada info en un gráfico. Diez series superpuestas no se leen. Si no se entiende de un vistazo, dividí en varios gráficos (subplots).

Ejemplo completo — tres vistas de un DataFrame

A partir de un DataFrame generamos un histograma, un scatter y un heatmap de correlación con seaborn. Tres preguntas distintas, tres gráficos:

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv("personas.csv")   # columnas: edad, altura, peso, sueldo

# 1) Distribución de una variable
sns.histplot(data=df, x="edad", bins=20)
plt.title("Distribución de edad")
plt.xlabel("Edad")
plt.ylabel("Frecuencia")
plt.show()

# 2) Relación entre dos variables
sns.scatterplot(data=df, x="altura", y="peso")
plt.title("Peso vs. altura")
plt.xlabel("Altura (cm)")
plt.ylabel("Peso (kg)")
plt.show()

# 3) Matriz de correlación entre todas las numéricas
corr = df.corr(numeric_only=True)
sns.heatmap(corr, annot=True, cmap="coolwarm", vmin=-1, vmax=1)
plt.title("Matriz de correlación")
plt.show()
Flujo mental: ¿una variable sola? → histograma. ¿dos variables? → scatter. ¿todas a la vez? → heatmap de correlación o pairplot. Empezá siempre por la pregunta, después elegís el gráfico.

Checkpoint — ¿lo tenés claro?

¿Qué demuestra el cuarteto de Anscombe?

Que datasets con estadísticas resumen idénticas (media, varianza, correlación, recta de regresión) pueden tener formas completamente distintas. Conclusión: siempre graficá, no confíes solo en los números.

¿Qué relación hay entre matplotlib y seaborn?

seaborn está construido encima de matplotlib: lo llama por debajo. seaborn da gráficos más lindos y funciones estadísticas (heatmap, boxplot, pairplot); matplotlib aporta el control fino y el plt.show(). Se usan juntos.

¿Qué gráfico uso para ver la relación entre dos variables numéricas? ¿Y la matriz de correlación?

Para la relación entre dos variables, un scatter (sns.scatterplot / plt.scatter). Para la matriz de correlación de muchas variables, un heatmap (sns.heatmap sobre df.corr()).
