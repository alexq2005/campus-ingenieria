El mismo width: 200px, resultados distintos

El outline dorado punteado representa el borde externo incluyendo el margin.

content-box
width 200px
box-sizing: content-box (default)
border-box
width 200px
box-sizing: border-box (recomendado)

¿Por qué border-box gana?

Cuando decís width: 200px, esperás que la caja sea de 200px. border-box hace que la matemática "simplemente funcione" como lo intuís.

Reset universal (ponelo siempre)

*,
*::before,
*::after {
  box-sizing: border-box;
}

Margin collapse — trampa clásica

Dos margin-bottom: 20px y margin-top: 30px seguidos no suman 50px: el mayor gana (30px). Solo pasa con márgenes verticales entre elementos block. En Flex/Grid no existe este bug.
