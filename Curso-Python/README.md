## Cómo usar este curso

1. Cada módulo tiene un archivo `.md` con teoría y una carpeta `ejemplos/` con código ejecutable.
2. **Lee la teoría primero**, después corre los ejemplos.
3. **No copies y pegues** — escribe el código a mano. La memoria muscular consolida la sintaxis.
4. Resuelve los ejercicios al final de cada módulo antes de avanzar.

## Requisitos

- Python 3.11 o superior — verificar con `python --version`
- Editor: VS Code, PyCharm o cualquier editor con resaltado de sintaxis
- Terminal (bash, PowerShell o cmd)

## Filosofía del curso

> "Lo simple es mejor que lo complejo. Lo complejo es mejor que lo complicado." — The Zen of Python

Cada módulo prioriza **claridad sobre completitud**. Mejor entender 80% bien que 100% mal.
