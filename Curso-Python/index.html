🐍 Curso de Python

De cero a proyectos reales en 15 módulos. Tipado dinámico, POO, concurrencia, biblioteca estándar, NumPy y proyectos integradores.
"Lo simple es mejor que lo complejo." — The Zen of Python

15 módulos 3 proyectos integradores Python 3.11+ CLI · POO · Async · Testing

📖 Cómo usar este curso

Cada módulo tiene un README.md con teoría y una carpeta ejemplos/ con código ejecutable.

1. Lee la teoría primero · 2. Corre los ejemplos · 3. Escribí el código a mano (no copy-paste) · 4. Resolvé los ejercicios antes de avanzar.

Requisitos: Python 3.11+, un editor (recomiendo VS Code), terminal.
