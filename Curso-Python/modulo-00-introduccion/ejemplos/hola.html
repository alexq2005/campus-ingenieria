hola.py — Primer programa

El tradicional "Hello World" con un toque interactivo: pide tu nombre y te saluda con un f-string.

Cómo ejecutar

# En una terminal, en el directorio del archivo:
python hola.py

# O explícitamente con Python 3:
python3 hola.py
Si python --version te muestra Python 2, usá python3. En sistemas modernos suele ya apuntar a Python 3.

Código fuente

⬇ Descargar .py 
"""Primer programa en Python — Modulo 00."""

print("Hola, mundo")
print("Bienvenido al curso de Python")

nombre = input("¿Cómo te llamás? ")
print(f"Hola, {nombre}. Estás listo para aprender.")

Conceptos del script

  • Docstring al inicio del archivo (entre """...""") — convención para describir el módulo.
  • print() — la función para imprimir texto a stdout.
  • input() — lee una línea desde stdin y la devuelve como string.
  • f-string: f"...{variable}..." — formateo moderno con interpolación.

Variaciones para practicar

  1. Pedir nombre Y apellido y saludar con ambos.
  2. Pedir la edad (con int(input())) y mostrar el año aproximado de nacimiento.
  3. Validar que el nombre no esté vacío; si lo está, pedir de nuevo.
  4. Saludo distinto según la hora actual (from datetime import datetime).
