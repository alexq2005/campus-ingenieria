Event Loop — orden

Código:

console.log('1 sync');
setTimeout(() => console.log('2 macro'), 0);
Promise.resolve().then(() => console.log('3 micro'));
Promise.resolve().then(() => console.log('4 micro'));
setTimeout(() => console.log('5 macro'), 0);
queueMicrotask(() => console.log('6 micro'));
console.log('7 sync');

¿En qué orden creés que saldrán? Presioná el botón y mirá el log:

Orden esperado: 1, 7, 3, 4, 6, 2, 5

Regla: sincrónico → vacía toda la microtask queue → toma una macrotask → vacía microtasks otra vez → siguiente macrotask.
