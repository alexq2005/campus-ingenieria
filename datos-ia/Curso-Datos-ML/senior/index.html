📊 Datos/ML Senior

El track experto. Del notebook que anda a un sistema de ML que aguanta producción — donde los modelos fallan silenciosos y correctos de forma.
"Un modelo es el único software que se degrada solo sin que nadie toque el código."

8 módulos PyTorch 2.5 · Serving LLMOps · RAG · vLLM QLoRA · Drift

📖 Para quién es

Para el que ya entrena modelos y ahora necesita que sobrevivan a producción: por qué el modelo da 94% en test y 71% en prod, por qué la GPU está al 40%, cómo se sirve un LLM sin fundirse en costos, cuándo RAG le gana a fine-tuning, y cómo te enterás de que el modelo se puso viejo antes de que el negocio se caiga.

Pre-requisito real: el Curso de Datos & ML completo (M00–M12). NumPy, pandas, scikit-learn y PyTorch básico tienen que estar cómodos.

Conecta con seguridad: los módulos de LLMOps y RAG cruzan con el CS4 — Seguridad de sistemas de IA del track de Ciberseguridad, porque en 2026 operar un LLM y asegurarlo son la misma conversación.

⚙️ Actualizado a septiembre de 2026. El track enseña el stack real de hoy: vLLM para servir LLMs, pgvector con reranking para RAG, QLoRA para fine-tunear un modelo de 8B en una GPU de consumo, DPO para preferencias, y Ragas para evaluar. La mitad del track es LLMOps porque ahí está el trabajo.
