Módulo 02 — pandas: Series y DataFrames

NumPy te dio arrays rápidos pero anónimos: posiciones numéricas, todo del mismo tipo. En el mundo real los datos vienen con nombres de columna, tipos mezclados (números, texto, fechas) y filas que querés identificar. Esa es la especialidad de pandas: la librería con la que vas a cargar, inspeccionar y manipular datos tabulares durante todo el resto del curso.

Las dos estructuras: Series y DataFrame

💡 Una Series es un array 1D con índice: una columna sola, donde cada valor tiene una etiqueta (el índice). Un DataFrame es una tabla 2D: varias Series pegadas, compartiendo el mismo índice de filas y con columnas que tienen nombre. De hecho, cada columna de un DataFrame es una Series.
🔍 El DataFrame es Excel en código: filas, columnas con nombre, celdas con valores. La diferencia es que en vez de hacer clic y arrastrar, escribís instrucciones reproducibles que funcionan igual sobre 10 filas o sobre 10 millones.

Crear datos: desde dict, listas, o (sobre todo) un archivo

Para practicar a veces creás un DataFrame a mano. La forma más común es desde un diccionario, donde cada clave es una columna:

import pandas as pd

# Una Series suelta (array 1D con índice)
s = pd.Series([10, 20, 30], index=["a", "b", "c"])

# Un DataFrame desde un dict: cada clave = una columna
df = pd.DataFrame({
    "nombre": ["Ana", "Beto", "Caro"],
    "edad":   [23, 35, 19],
    "ciudad": ["CABA", "Rosario", "CABA"],
})
En la práctica casi nunca tipeás los datos a mano: los cargás desde un archivo. El caballo de batalla es pd.read_csv. 
df = pd.read_csv("datos.csv")              # lo más común
df = pd.read_csv("datos.csv", sep=";")     # separador distinto (CSV "europeo")
df = pd.read_excel("datos.xlsx")           # planillas de Excel
df = pd.read_json("datos.json")            # JSON (APIs, exports)
📌 Importás pandas casi siempre como pd (import pandas as pd). Es la convención universal: todo tutorial, doc y respuesta de Stack Overflow asume ese alias.

Seleccionar columnas: Series vs DataFrame

Acá hay una distinción sutil pero importante. Cómo seleccionás cambia qué tipo de objeto recibís:

df["edad"]              # corchetes simples → una Series (1D)
df[["edad", "ciudad"]]  # lista dentro → un DataFrame (2D), aunque sea 1 columna
💡 La regla: df["col"] (una string) devuelve una Series. df[["col1", "col2"]] (una lista de strings) devuelve un DataFrame. Si querés un DataFrame de una sola columna, usás la lista: df[["edad"]].

loc vs iloc: las dos formas de indexar filas

Para seleccionar filas (o filas y columnas juntas) pandas te da dos accesores. La diferencia es por qué identificás lo que querés:

.loc.iloc
Selecciona porEtiqueta (el índice / nombre de columna)Posición (número entero, como en NumPy)
Rango incluye el finalSí — df.loc[0:2] trae 0, 1 y 2No — df.iloc[0:2] trae 0 y 1
Ejemplo filadf.loc[0] (fila con índice 0)df.iloc[0] (primera fila)
Ejemplo celdadf.loc[0, "edad"]df.iloc[0, 1]
 
# .loc → por ETIQUETA (incluye el final del rango)
df.loc[0]                    # la fila cuyo índice es 0
df.loc[0:2, "nombre"]        # filas 0,1,2 de la columna "nombre"
df.loc[df["edad"] > 18]      # también acepta máscaras booleanas

# .iloc → por POSICIÓN (excluye el final, como Python normal)
df.iloc[0]                   # la primera fila (sea cual sea su índice)
df.iloc[0:2, 0:2]            # filas 0-1, columnas 0-1
df.iloc[-1]                  # la última fila

Filtrado booleano: el corazón del análisis

Comparar una columna contra un valor produce una Series de True/False (una "máscara"). Si pasás esa máscara entre corchetes, pandas se queda solo con las filas donde es True:

df["edad"] > 18              # Series de booleanos: True/False por fila
df[df["edad"] > 18]          # solo las filas donde la edad supera 18

Para combinar varias condiciones se usan los operadores elemento a elemento: & (y), | (o), ~ (no). Y cada condición va entre paréntesis:

# mayores de 18 Y de CABA
df[(df["edad"] > 18) & (df["ciudad"] == "CABA")]

# menores de 18 O mayores de 65
df[(df["edad"] < 18) | (df["edad"] > 65)]

# que NO sean de CABA
df[~(df["ciudad"] == "CABA")]
📌 Usá & y |, no and / or. Los operadores de Python (and, or) trabajan sobre un único valor booleano; pandas necesita comparar columna entera contra columna entera, elemento por elemento. Y siempre paréntesis alrededor de cada condición, porque & tiene más precedencia que >.

Crear y modificar columnas, y ordenar

Asignar a una columna que no existe la crea; asignar a una que existe la reemplaza. Las operaciones son vectorizadas (sobre toda la columna a la vez, herencia de NumPy):

# columna derivada: precio con IVA
df["precio_final"] = df["precio"] * 1.21

# columna a partir de otra: nombre en mayúsculas
df["nombre_mayus"] = df["nombre"].str.upper()

# ordenar por una columna (descendente)
df.sort_values("edad", ascending=False)

# ordenar por varias columnas a la vez
df.sort_values(["ciudad", "edad"])
sort_values devuelve un DataFrame nuevo ordenado; no modifica el original salvo que pases inplace=True (preferí reasignar: df = df.sort_values(...), es más claro).

Errores típicos

Confundir loc con iloc. loc es por etiqueta e incluye el final del rango; iloc es por posición y lo excluye. Si el índice del DataFrame no es 0,1,2,… (porque filtraste o lo reindexaste), df.loc[0] y df.iloc[0] pueden traer filas distintas.
Chained indexing y el SettingWithCopyWarning. Escribir df[df["edad"] > 18]["ciudad"] = "X" encadena dos operaciones: pandas no sabe si modificás el original o una copia, y te avisa con SettingWithCopyWarning. La forma correcta es una sola llamada a .loc: df.loc[df["edad"] > 18, "ciudad"] = "X".
Filtrar sin paréntesis al combinar condiciones. df[df["edad"] > 18 & df["ciudad"] == "CABA"] falla, porque & se evalúa antes que >. Siempre: df[(df["edad"] > 18) & (df["ciudad"] == "CABA")].
Usar and / or en vez de & / |. Da el error The truth value of a Series is ambiguous: Python intenta convertir una columna entera a un solo True/False y no puede.

Ejemplo completo: cargar, filtrar, derivar, ordenar

Un flujo realista de punta a punta sobre un CSV de empleados:

import pandas as pd

# 1. Cargar
df = pd.read_csv("empleados.csv")

# 2. Mirar qué hay
print(df.shape)        # (250, 4)
print(df.dtypes)       # nombre: object, edad: int64, salario: float64, area: object

# 3. Filtrar: adultos del área de Ventas
ventas = df[(df["edad"] >= 18) & (df["area"] == "Ventas")]

# 4. Crear una columna derivada: salario anual
ventas["salario_anual"] = ventas["salario"] * 12

# 5. Ordenar por salario anual, de mayor a menor
ranking = ventas.sort_values("salario_anual", ascending=False)

print(ranking.head())
💡 En el paso 4, como ventas es un sub-DataFrame filtrado, pandas podría tirar SettingWithCopyWarning. La forma robusta es hacer una copia explícita al filtrar: ventas = df[...].copy(). Así dejás claro que ventas es un objeto propio que vas a modificar.

Checkpoint — ¿lo tenés claro?

¿Qué diferencia hay entre df["col"] y df[["col"]]?

df["col"] (string) devuelve una Series (1D). df[["col"]] (lista con una string) devuelve un DataFrame (2D) de una sola columna. La lista siempre da DataFrame.

Si filtraste un DataFrame, ¿df.loc[0] y df.iloc[0] traen lo mismo?

No necesariamente. Después de filtrar, el índice conserva las etiquetas originales (puede ser 0, 5, 12…). iloc[0] trae la primera fila por posición; loc[0] trae la fila cuya etiqueta es 0, que tal vez ni exista en el subconjunto.

¿Por qué df[df["a"] > 1 & df["b"] < 2] falla?

Porque & tiene mayor precedencia que > y <, así que Python intenta evaluar 1 & df["b"] primero. Hay que envolver cada condición en paréntesis: df[(df["a"] > 1) & (df["b"] < 2)].

🧠 Autoevaluación

1. ¿Cuál es la diferencia entre .loc e .iloc?

.loc usa las etiquetas del índice y los nombres de columna (e incluye el final del rango). .iloc usa posiciones enteras, como NumPy (y excluye el final).

2. ¿Cómo filtrás las filas con edad > 18 Y ciudad == "CABA"?

Se combinan con & (no and) y cada condición va entre paréntesis, porque & tiene más precedencia que los comparadores.

3. ¿Qué devuelve df["edad"] (corchetes simples, una string)?

df["col"] con una string devuelve una Series. Para obtener un DataFrame de una columna usás una lista: df[["edad"]].
