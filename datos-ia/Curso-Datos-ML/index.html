📊 Datos & Machine Learning

De cargar un CSV a entrenar una red neuronal. El stack real de la ciencia de datos: NumPy, pandas, visualización, scikit-learn y PyTorch.
"En Dios confiamos; los demás traigan datos." — atribuido a W. E. Deming

13 módulos pandas + scikit-learn + PyTorch Python 3.11+ Jupyter / notebooks

📖 De qué se trata

La ciencia de datos es un pipeline: cargar → limpiar → explorar → visualizar → modelar → evaluar. Este curso recorre ese flujo con las herramientas que se usan en la industria, terminando en deep learning con PyTorch.

Pre-requisito real: el Curso de Python (incluido su Módulo 14 — NumPy, que es la base de todo esto). La teoría matemática vive en el área de IA & Datos de Ingeniería en Sistemas.

Conecta con: el proyecto P30 Red Neuronal desde Cero (lo que hacés a mano acá, después lo hacés con framework) y P16 Clasificador CNN.
