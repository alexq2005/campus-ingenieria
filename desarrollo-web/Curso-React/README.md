# Curso de React — CS-FE Campus

> "Learn once, write anywhere." — Filosofía React

15 módulos desde JSX y hooks hasta React Server Components con Next.js 15.

## Stack del curso

- **React 19** (stable 2025)
- **TypeScript** (en M13 en adelante; opcional antes)
- **Vite 6** para módulos M00-M12
- **Next.js 15** (App Router + RSC) para M13-M14
- **React Router 7**, **TanStack Query 5**, **Zustand**, **Vitest**, **Testing Library**

## Prerequisitos

- HTML y CSS modernos
- JavaScript ES2022+ (arrow functions, destructuring, async/await, modules)
- Git básico
- Node.js 24+ instalado

Si te falta alguno: hacer primero el [Curso de Frontend](../index.html) (módulos 02-07).

## Cómo seguir el curso

1. Lee `lecture.html` de cada módulo (abrir con doble click en el browser).
2. Replicá los ejemplos en un proyecto Vite local o CodeSandbox.
3. Resolvé los ejercicios al final de cada módulo.
4. Cada 4-5 módulos: armá un mini-proyecto que integre lo aprendido.
5. Al final: el proyecto integrador del M14.
