# Módulo 14 — Proyecto Integrador (Capstone)

> ⏱ ~2-3 semanas · Pre-req: Todo el curso

📖 **[Leer la lección completa (lecture.html)](./lecture.html)**

## Qué construís

Un **Dashboard de Productividad Personal** que integra TODO lo aprendido: auth, CRUD, stats, real-time, dark mode, responsive, tests y deploy.

## Stack final

Next.js 15 + TypeScript + Tailwind + shadcn/ui + Clerk (auth) + Neon Postgres + Drizzle ORM + TanStack Query + Zustand + Recharts + Vitest + Playwright + Vercel.

## Plan en 5 fases (~18 días)

1. **Setup** (día 1-2): Next.js + Tailwind + shadcn + Neon + CI + primer deploy.
2. **Auth + Schema** (día 3-5): Clerk + Drizzle schema + rutas protegidas.
3. **CRUD Tareas** (día 6-10): Server Components + Server Actions + optimistic + filtros + categorías.
4. **Stats + Real-time** (día 11-14): Recharts + Supabase Realtime / Pusher.
5. **Polish + Deploy** (día 15-18): dark mode, responsive, tests, SEO, Lighthouse >90, README.

## Criterios de "done"

URL pública + auth real + CRUD completo + feature wow + responsive + dark mode + Lighthouse >90 + tests + README + GitHub público + CI/CD.

## Variantes alternativas

Chat app, e-commerce mini, blog/CMS, quiz app, habit tracker, Notion-clone, Spotify-clone.

## Lo importante

No es ser original — es **terminar**. Un dashboard terminado y deployado > un Notion-clone a medias.
