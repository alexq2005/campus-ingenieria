📖 Cómo usar este curso

Cada módulo tiene un lecture.html con teoría, ejemplos y ejercicios prácticos.

1. Lee la teoría · 2. Codeá los ejemplos en CodeSandbox o Vite local · 3. Resolvé los ejercicios.

Prerequisito: dominar HTML, CSS y JavaScript moderno (ES2022+). Si te falta alguno, primero el Curso de Frontend.

🎮 Demos interactivos (corren en el browser): useState Playground · useEffect Visualizer
💪 Ejercicios resueltos con soluciones plegables.
