📖 Para quién es

Para el que ya construye con React y ahora necesita responder por qué: por qué la lista se traba al tipear, por qué memo no sirvió, por qué el useEffect corre dos veces, o si conviene migrar a Server Components.

Pre-requisito real: el Curso de React completo (M00–M14). Hooks, Router, data fetching y estado global tienen que estar cómodos.

Complementa al Track Senior de Frontend, que cubre lo que NO es específico de React: patrones y arquitectura, state machines, estrategia de testing, seguridad, observabilidad, microfrontends, patrones de API y liderazgo técnico. Este track no los repite — los referencia.

⚙️ Actualizado a septiembre de 2026. El React Compiler llegó a 1.0 y Meta lo usa en producción en Instagram: eso cambió qué significa "React avanzado" — el track enseña a verificar qué componentes quedan afuera del compilador, no a repartir useMemo. Y RSC y Server Functions son estables en React 19.
