📱 React Native Senior

El track experto. Lo que separa una app que "funciona" de una que se siente nativa, arranca rápido y se puede operar en producción.
"El puente ya no existe. Casi todo lo que vas a leer en internet no se enteró."

8 módulos JSI · Fabric · TurboModules RN 0.86 bridgeless EAS · OTA · Observabilidad

📖 Para quién es

Para el que ya publica apps con React Native y ahora necesita responder por qué: por qué la lista va a tirones, por qué la animación salta cuando llega un fetch, por qué la app arranca en 4 segundos, o cómo se arregla un bug crítico cuando ya está instalada en 50.000 teléfonos.

Pre-requisito real: el Curso de React Native completo (M00–M12), y conviene tener el track de React Senior — sobre todo RS1, porque el reconciliador es el mismo.

Qué lo hace distinto: cada módulo baja al nivel de los hilos, la memoria y el ciclo de vida real de una app móvil, con medición en dispositivos de gama media y no en el iPhone del desarrollador.

⚙️ Actualizado a septiembre de 2026 — y esto importa más que en ningún otro track. La Nueva Arquitectura es el default desde RN 0.76, la 0.82 eliminó el Bridge por completo (poner newArchEnabled=false se ignora, no hay vuelta atrás) y la 0.86 es bridgeless total con Strict TypeScript API vía Codegen. La enorme mayoría del material que vas a encontrar sigue explicando el puente asíncrono como si existiera.

RNS3
