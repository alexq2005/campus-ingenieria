📖 Por qué este curso es un atajo para vos

React Native usa el mismo React que ya estudiaste: componentes, props, useState, useEffect, hooks. Lo que cambia no es el lenguaje, son las piezas: en vez de <div> y <p> usás <View> y <Text>; en vez de CSS usás objetos de estilo; y ganás acceso a cosas que la web no tiene (cámara, GPS, notificaciones push).

Pre-requisito real: el Curso de React (al menos M00–M08: componentes, estado, hooks). Si eso lo tenés, el 70% de este curso ya lo sabés.

Herramientas: Node.js, Expo (el toolkit que hace todo fácil) y la app Expo Go en tu celular para ver tu app al instante.
