Módulo 02 — Estilos sin CSS

En la web pintabas todo con archivos .css y clases. En React Native eso no existe: no hay hojas de estilo, no hay clases, no hay selectores. Los estilos son objetos de JavaScript. En este módulo vas a aprender a estilar componentes nativos, a entender por qué Flexbox funciona "al revés" que en la web, y a armar una tarjeta prolija con sombra y bordes.

No hay CSS: los estilos son objetos JS

💡 En React Native no escribís CSS. Cada componente recibe una prop style que toma un objeto de JavaScript donde las claves son propiedades y los valores son números o strings. No hay archivos .css, no hay clases, no hay cascada ni selectores. El estilo vive en el mismo archivo, como un objeto más.

La forma recomendada de crear esos objetos es StyleSheet.create. Lo importás de react-native y le pasás un objeto con tus estilos:

import { View, Text, StyleSheet } from 'react-native';

export default function Tarjeta() {
  return (
    <View style={styles.caja}>
      <Text style={styles.titulo}>Hola estilos</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  caja: { padding: 16, backgroundColor: '#1e293b', borderRadius: 12 },
  titulo: { color: 'white', fontSize: 18, fontWeight: 'bold' },
});
¿Por qué StyleSheet.create y no un objeto suelto? Funciona igual con un objeto literal (style={{ padding: 16 }}), pero StyleSheet.create valida las propiedades en desarrollo (te avisa si escribís mal una clave) y deja el código más ordenado al separar la lógica de los estilos.

camelCase y unidades: lo que cambia de sintaxis

La traducción desde CSS es casi mecánica, pero hay dos diferencias que tropiezan a todo el mundo:

📌 Regla 1 — camelCase. Las propiedades con guion en CSS se escriben en camelCase: background-color → backgroundColor, font-size → fontSize, border-radius → borderRadius.
📌 Regla 2 — sin px. Los tamaños son números, no strings con unidad: fontSize: 18, no fontSize: '18px'. Esos números son density-independent pixels (dp): RN los escala según la densidad de la pantalla, así tu UI se ve igual de grande en un celular barato y en uno con pantalla retina.

Flexbox viene por defecto (y al revés que la web)

💡 En React Native todo es Flexbox, sin pedirlo. No necesitás escribir display: flex: cada <View> ya es un contenedor flex. Y lo más importante: flexDirection por defecto es 'column' (los hijos se apilan de arriba hacia abajo), al revés que en la web, donde el default de un contenedor flex es 'row'.

Esto tiene sentido cuando lo pensás: una pantalla de celular es alta y angosta, así que apilar verticalmente es lo natural. Las herramientas de siempre funcionan igual:

PropiedadQué hace
flex: 1el componente ocupa todo el espacio disponible de su contenedor
flexDirection'column' (default, vertical) o 'row' (horizontal)
justifyContentalinea sobre el eje principal (la dirección del flex)
alignItemsalinea sobre el eje cruzado (perpendicular)

const styles = StyleSheet.create({
  // pantalla completa, contenido centrado vertical y horizontalmente
  pantalla: {
    flex: 1,
    justifyContent: 'center',  // eje principal (vertical, porque es column)
    alignItems: 'center',      // eje cruzado (horizontal)
    gap: 12,
  },
  // una fila de botones, lado a lado
  fila: {
    flexDirection: 'row',      // ahora SÍ horizontal
    justifyContent: 'space-between',
    gap: 8,
  },
});
🔍 Mismo Flexbox del Curso de React/CSS. justifyContent, alignItems, flex: 1 y gap hacen exactamente lo que ya sabés. Lo único que tenés que reprogramar en tu cabeza es que el eje principal por defecto es vertical, no horizontal.

Dimensiones: números, porcentajes y pantalla

Para dar tamaño a las cosas tenés tres caminos, de menos a más dinámico:

1. Números fijos (dp). Lo más simple: width: 200, height: 80. Útil para íconos, avatares, botones de tamaño conocido.
2. Porcentajes (string). Relativo al contenedor padre: width: '100%', width: '50%'. Acá sí va string, porque lleva el símbolo %.
3. Tamaño de la pantalla. Cuando necesitás reaccionar al ancho real del dispositivo, usás el hook useWindowDimensions:
import { View, Text, useWindowDimensions, StyleSheet } from 'react-native';

export default function Banner() {
  const { width, height } = useWindowDimensions(); // se actualiza al rotar el celular

  return (
    <View style={[styles.banner, { width: width * 0.9 }]}>
      <Text>Ancho de pantalla: {Math.round(width)}dp</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  banner: { padding: 16, backgroundColor: '#334155', borderRadius: 10 },
});
Existe también Dimensions.get('window') (import de react-native), pero devuelve un valor fijo tomado una sola vez. El hook useWindowDimensions es mejor porque se re-renderiza solo cuando el usuario rota el celular o cambia el tamaño. Preferí el hook.

Combinar estilos: arrays y condicionales

💡 La prop style también acepta un array de estilos. RN los fusiona de izquierda a derecha (el último gana en caso de conflicto). Esto reemplaza la idea de "poner varias clases" de la web: style={[estilo1, estilo2]}. 
// fusiona base + extra; si chocan, gana el de la derecha
<View style={[styles.caja, styles.cajaDestacada]} />

El patrón más potente es el estilo condicional. Usás && para aplicar un estilo solo cuando una condición es verdadera. Si la condición es falsa, RN ignora el false sin romper:

import { useState } from 'react';
import { Pressable, Text, StyleSheet } from 'react-native';

export default function Chip() {
  const [activo, setActivo] = useState(false);

  return (
    <Pressable
      onPress={() => setActivo(!activo)}
      style={[styles.base, activo && styles.activo]}  // ⬅️ estilo condicional
    >
      <Text style={[styles.texto, activo && styles.textoActivo]}>
        {activo ? 'Seleccionado' : 'Tocá para elegir'}
      </Text>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  base: { padding: 12, borderRadius: 999, borderWidth: 1, borderColor: '#475569' },
  activo: { backgroundColor: '#a78bfa', borderColor: '#a78bfa' },
  texto: { color: '#94a3b8', fontWeight: '600' },
  textoActivo: { color: 'white' },
});
📌 El patrón clave: style={[base, condición && estiloExtra]}. Cuando condición es true, se aplica estiloExtra encima de base; cuando es false, el array contiene false y RN simplemente lo descarta.

Tema claro/oscuro con useColorScheme

Los celulares tienen un ajuste de modo claro/oscuro a nivel sistema. RN te lo expone con el hook useColorScheme, que devuelve 'light' o 'dark' y se actualiza solo cuando el usuario lo cambia:

import { View, Text, useColorScheme, StyleSheet } from 'react-native';

export default function Pantalla() {
  const esquema = useColorScheme();        // 'light' | 'dark'
  const oscuro = esquema === 'dark';

  return (
    <View style={[styles.fondo, oscuro && styles.fondoOscuro]}>
      <Text style={[styles.texto, oscuro && styles.textoOscuro]}>
        Estoy en modo {esquema}
      </Text>
    </View>
  );
}

const styles = StyleSheet.create({
  fondo: { flex: 1, justifyContent: 'center', alignItems: 'center', backgroundColor: '#ffffff' },
  fondoOscuro: { backgroundColor: '#0f172a' },
  texto: { color: '#0f172a', fontSize: 18 },
  textoOscuro: { color: '#f8fafc' },
});
🔍 Es el mismo patrón condicional de la sección anterior, aplicado a un tema. El hook te dice el modo del sistema y vos decidís qué estilo extra sumar con oscuro && styles.algoOscuro.

Ejemplo completo: una tarjeta estilizada

Juntemos todo en una tarjeta real, con sombra, bordes redondeados y padding. Ojo con la sombra: iOS y Android la manejan distinto, así que se ponen ambas propiedades.

import { View, Text, Image, StyleSheet } from 'react-native';

export default function TarjetaPerfil() {
  return (
    <View style={styles.tarjeta}>
      <Image
        style={styles.avatar}
        source={{ uri: 'https://i.pravatar.cc/120' }}
      />
      <View style={styles.info}>
        <Text style={styles.nombre}>Ada Lovelace</Text>
        <Text style={styles.rol}>Programadora pionera</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  tarjeta: {
    flexDirection: 'row',       // avatar + info, lado a lado
    alignItems: 'center',
    gap: 14,
    padding: 16,
    backgroundColor: '#ffffff',
    borderRadius: 16,
    borderWidth: 1,
    borderColor: '#e2e8f0',
    // sombra en iOS:
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.15,
    shadowRadius: 8,
    // sombra en Android:
    elevation: 4,
  },
  avatar: { width: 56, height: 56, borderRadius: 28 },  // círculo perfecto
  info: { gap: 2 },
  nombre: { fontSize: 17, fontWeight: 'bold', color: '#0f172a' },
  rol: { fontSize: 13, color: '#64748b' },
});
Sombra multiplataforma: shadowColor/Offset/Opacity/Radius son para iOS; elevation (un número) es para Android. Poné ambas para que la sombra se vea en los dos sistemas. Y para hacer un círculo, usá borderRadius igual a la mitad del ancho/alto.

Errores típicos al estilar

Esperar flexDirection: 'row' por defecto. Venís de la web y armás una fila… pero los elementos te quedan apilados verticalmente. El default es 'column'. Si querés fila, ponelo explícito: flexDirection: 'row'.
Usar sintaxis CSS. 'background-color' en vez de backgroundColor, o fontSize: '18px' en vez de fontSize: 18. Las propiedades van en camelCase y los tamaños son números sin unidad.
Estilos inline desordenados. Tirar style={{ padding: 16, margin: 8, ... }} en cada componente ensucia el JSX y repite código. Movelos a un StyleSheet.create al pie del archivo.

Checkpoint — ¿lo tenés claro?

¿Cómo escribís background-color: #222 en React Native?

En camelCase y con el color como string: backgroundColor: '#222'. No hay guiones ni archivos .css; es una propiedad dentro del objeto que le pasás a style.

Apilaste dos <Text> dentro de un <View> y querés que queden lado a lado. ¿Qué te falta?

Agregar flexDirection: 'row' al estilo del <View>. Por defecto RN usa 'column' (vertical), así que sin eso los hijos se apilan de arriba hacia abajo.

¿Cómo aplicás un estilo solo cuando una variable activo es verdadera?

Con un array y &&: style={[styles.base, activo && styles.activo]}. Si activo es false, RN descarta el valor y queda solo styles.base.

Ejercicios

  1. Creá una <View> con flex: 1 que centre un <Text> en el medio de la pantalla usando justifyContent y alignItems.
  2. Armá una fila de tres cuadrados de colores con flexDirection: 'row' y gap entre ellos. Probá quitar el flexDirection y observá cómo se apilan.
  3. Reescribí la tarjeta de perfil del ejemplo y cambiá el avatar a un cuadrado con esquinas redondeadas (jugá con borderRadius).
  4. Hacé un "chip" que cambie de color de fondo al tocarlo, usando useState y el patrón style={[base, activo && extra]}.
  5. Usá useColorScheme para que el fondo y el texto de una pantalla cambien entre modo claro y oscuro según el ajuste del sistema.
