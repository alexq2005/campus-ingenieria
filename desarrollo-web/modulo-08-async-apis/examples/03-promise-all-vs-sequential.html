Paralelo vs Secuencial

Simulamos 5 requests de 500ms cada uno. Mirá los tiempos totales.

Paralelo (Promise.all)

—

Secuencial (await uno por uno)

—
// Paralelo — se disparan todas al mismo tiempo
await Promise.all([fn(), fn(), fn(), fn(), fn()]);
// Tiempo total ≈ la request más lenta

// Secuencial — espera cada una antes de la próxima
for (let i = 0; i < 5; i++) await fn();
// Tiempo total ≈ suma de todas las requests

Cuándo usar secuencial: cuando la request N depende del resultado de N-1.
