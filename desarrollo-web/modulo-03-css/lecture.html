1. Según la regla de oro de performance del módulo, ¿qué propiedades conviene animar?

Solo transform y opacity se resuelven en la etapa de composite (GPU). Animar tamaños o márgenes dispara re-layout en cada frame y hace que la animación se sienta trabada.

2. ¿En qué se diferencia :where(h1, h2, h3) de :is(h1, h2, h3)?

Por eso :where() es ideal para estilos base de una librería: el usuario puede sobrescribirlos con cualquier clase sin pelear con la especificidad. Recordá el orden del cálculo: inline > IDs > clases/atributos/pseudo-clases > tipos.

3. ¿Qué hace position: sticky?

La opción 1 describe position: fixed y la 3 describe position: absolute. sticky necesita sí o sí un umbral declarado (top: 0, por ejemplo) para saber cuándo pegarse.
