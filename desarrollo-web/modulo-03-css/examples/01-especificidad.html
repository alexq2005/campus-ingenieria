Laboratorio de especificidad CSS

Inspeccioná cada p con DevTools (Elements → Styles) para ver qué regla ganó y por qué.

A) Solo tipo p → especificidad 0,0,0,1

B) Clase .destacado → 0,0,1,0 (gana sobre A)

C) Dos clases .destacado.urgente → 0,0,2,0 (gana sobre B)

D) ID #especial → 0,1,0,0 (gana sobre cualquier cantidad de clases)

E) ID + clase → 0,1,1,0 (gana sobre D)

F) Inline style → 1,0,0,0 (gana sobre D y E)

G) !important rompe la cascada — evitalo

Ejercicio mental

Dadas las reglas:

ul li a         { color: red; }     /* ? */
.nav a          { color: blue; }    /* ? */
nav ul li a     { color: green; }   /* ? */
.nav .link      { color: orange; }  /* ? */
#main .link     { color: purple; }  /* ? */

Calculá la especificidad de cada una. ¿Cuál gana sobre un enlace <a class="link"> dentro de <ul class="nav"> dentro de <nav id="main">?

Respuesta: 0,1,1,0 — purple (el selector con ID).
