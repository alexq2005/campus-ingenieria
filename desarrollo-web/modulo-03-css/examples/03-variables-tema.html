Sistema de diseño con CSS variables

Presiona el botón arriba-derecha. Inspeccioná el <html> en DevTools y observá cómo cambia data-theme.

Tarjeta 1

Toda esta tarjeta usa variables: --surface, --text, --border, --shadow, --radius. Cambiar el tema actualiza todo al mismo tiempo.

Tarjeta 2

Variables CSS son dinámicas — se pueden leer y modificar con JavaScript:

getComputedStyle(document.documentElement)
  .getPropertyValue('--primary')

Regla clave

Definí tu paleta, espaciado y radios como variables desde el día 1. No pongas valores literales (#0ea5e9, 16px) en las reglas. Tu "yo del futuro" te lo agradecerá.
