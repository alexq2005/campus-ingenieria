Métodos de array — problemas reales resueltos

Abrí la consola para ver trazas detalladas. La "salida" abajo muestra los resultados.

1. Dado un array de usuarios, obtener solo los nombres de los mayores de 18

const usuarios = [
  { nombre: 'Ada', edad: 30 },
  { nombre: 'Lin', edad: 15 },
  { nombre: 'Bob', edad: 22 },
];
const adultos = usuarios
  .filter(u => u.edad >= 18)
  .map(u => u.nombre);

2. Sumar el precio total del carrito

const carrito = [
  { item: 'Libro', precio: 1200, cantidad: 2 },
  { item: 'Café',  precio: 500,  cantidad: 3 },
  { item: 'Lápiz', precio: 100,  cantidad: 10 },
];
const total = carrito.reduce((acc, p) => acc + p.precio * p.cantidad, 0);

3. Agrupar por categoría

const productos = [
  { nombre: 'Camisa', cat: 'ropa' },
  { nombre: 'Pantalón', cat: 'ropa' },
  { nombre: 'Mesa', cat: 'muebles' },
  { nombre: 'Silla', cat: 'muebles' },
  { nombre: 'Lámpara', cat: 'deco' },
];
const agrupado = productos.reduce((acc, p) => {
  (acc[p.cat] ??= []).push(p.nombre);
  return acc;
}, {});

const conRepetidos = [1, 2, 2, 3, 3, 3, 4];

5. Estadísticas: promedio, max, min

const notas = [7, 8, 9, 10, 6, 7];
const stats = {
  promedio: notas.reduce((a,b) => a+b, 0) / notas.length,
  max: Math.max(...notas),
  min: Math.min(...notas),
  aprobados: notas.filter(n => n >= 7).length,
};

6. Ordenar por precio descendente

const items = [
  { n: 'A', p: 50 },
  { n: 'B', p: 20 },
  { n: 'C', p: 100 },
];
const ordenados = [...items].sort((a, b) => b.p - a.p);
