Playground de JavaScript

Abrí DevTools → pestaña Console (F12). Vas a ver la salida de cada sección. Jugá con el código copiándolo y modificándolo.

Tip: la consola acepta JavaScript directo. Probá escribir 1 + 1 y Enter.

1. Tipos primitivos

console.log(typeof 'hola');    // 'string'
console.log(typeof 42);         // 'number'
console.log(typeof null);       // 'object' — bug histórico

2. Operadores

console.log('0' == false);   // true — evitá ==
console.log('0' === false);  // false — usá siempre ===

3. Arrays con métodos funcionales

const nums = [1, 2, 3, 4, 5];
const resultado = nums
  .filter(n => n % 2 === 0)   // [2, 4]
  .map(n => n * n)             // [4, 16]
  .reduce((a, b) => a + b, 0); // 20
console.log(resultado);

4. Objetos y destructuring

const persona = { nombre: 'Ada', edad: 30, ciudad: 'Londres' };
const { nombre, edad } = persona;
console.log(`${nombre} tiene ${edad} años`);

5. Closures

function contador() {
  let n = 0;
  return () => ++n;
}
const c = contador();
console.log(c(), c(), c()); // 1 2 3
