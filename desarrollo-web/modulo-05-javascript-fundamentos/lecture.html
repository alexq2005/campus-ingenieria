🧠 Autoevaluación rápida

Respondé sin mirar arriba. Cada pregunta te explica el porqué.

1. ¿Qué diferencia hay entre <script defer> y <script async>?

La recomendación del módulo: poné el script en el <head> con defer o, mejor, con type="module" (que trae defer implícito). async queda para cosas independientes como analytics.

2. ¿Qué devuelve typeof null?

Es el error más famoso del lenguaje: quedó desde 1995 y arreglarlo rompería medio internet. Ojo también con los arrays: typeof [1,2] también da 'object' — para eso está Array.isArray().

3. Corrés const a = { x: 1 }; const b = a; b.x = 99; — ¿cuánto vale a.x?

const impide reasignar la variable, no mutar el objeto al que apunta. Si querés una copia independiente: { ...a } (superficial) o structuredClone(a) (profunda).
