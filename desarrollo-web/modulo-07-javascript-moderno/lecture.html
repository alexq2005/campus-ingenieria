🧠 Autoevaluación rápida

Respondé sin mirar arriba. Cada pregunta te explica el porqué.

1. ¿Qué devuelve 0 ?? 42?

El nullish coalescing ?? solo cae al valor de la derecha si el de la izquierda es null o undefined. 0 es un valor perfectamente válido, así que gana. Con || sí habrías obtenido 42, porque 0 es falsy — esa es justamente la diferencia entre los dos operadores.

2. En un objeto literal, saludarArrow: () => this.nombre devuelve undefined. ¿Por qué?

La arrow se definió en el scope exterior al objeto, así que su this es el de afuera (el global), no el objeto. Por eso la regla es: arrow para callbacks, function normal (o método corto saludar() { ... }) para métodos de objetos.

3. ¿Qué trae de fábrica un <script type="module">?

Un módulo ES no ensucia window, corre siempre en modo estricto y espera a que el HTML esté parseado. La contra: necesita servirse por HTTP — abrir el archivo con file:// directo falla, así que hace falta un dev server.
