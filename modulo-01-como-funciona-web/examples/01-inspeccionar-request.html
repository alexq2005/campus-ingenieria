Abrí DevTools (F12) → pestaña Network → recargá con Ctrl+R.

Vas a ver este mismo archivo en la lista de requests. Cliqueá sobre él:

  • Headers: mirá qué envió tu navegador y qué devolvió el "servidor" (en este caso, el disco).
  • Timing: cuánto tardó cada fase (DNS, conexión, descarga).
  • Response: el HTML crudo que el navegador parseó.
