🔑 La magia de las keys

Cuando tenés listas, React necesita saber cuál item es cuál entre renders. Si usás key={'{index}'}, al reordenar React piensa que TODOS cambiaron (patches = N). Con key={'{id}'} estable, React mueve los nodos existentes (patches ≈ 1–2). Probá los escenarios 4 y 5 y compará el número de patches.
