💡 Claves del DOM

· DOM ≠ HTML. HTML es texto; DOM es el árbol de objetos que el browser construye a partir de él.
· Cada nodo tiene: nodeName, nodeType, childNodes, parentNode, attributes.
· nodeType: 1 = Element, 3 = Text, 8 = Comment, 9 = Document.
· childNodes incluye text nodes (espacios, saltos de línea). children solo elementos.
