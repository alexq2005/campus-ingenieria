tipos.py — Variables y tipos primitivos

Demostración práctica de tipos primitivos, type hints, conversión, falsy values y f-strings con formato avanzado.

Cómo ejecutar

python tipos.py

Código fuente

⬇ Descargar .py 
"""Ejemplos de variables y tipos primitivos."""

# Tipos primitivos
nombre: str = "Ana"
edad: int = 30
altura: float = 1.65
activo: bool = True
saldo: float | None = None  # union type, Python 3.10+

print(f"{nombre=}, {type(nombre).__name__=}")
print(f"{edad=}, {type(edad).__name__=}")
print(f"{altura=}, {type(altura).__name__=}")
print(f"{activo=}, {type(activo).__name__=}")

# Conversión
texto_numero = "123"
numero = int(texto_numero)
print(f"'{texto_numero}' como int: {numero}")
print(f"{numero} como str: '{str(numero)}'")

# Falsy values
for valor in [0, "", None, [], {}, "hola", 42, [1]]:
    print(f"bool({valor!r}) = {bool(valor)}")

# F-strings con formato
pi = 3.14159
print(f"PI con 2 decimales: {pi:.2f}")
print(f"PI con 4 decimales: {pi:.4f}")
print(f"Número grande: {1234567:,}")
print(f"Porcentaje: {0.875:.1%}")
print(f"Padding: '{42:>10}'")  # alineado derecha
print(f"Padding: '{42:<10}'")  # alineado izquierda
print(f"Padding: '{42:^10}'")  # centrado

Conceptos clave

  • Type hints: nombre: str = "Ana" — anotación opcional, no afecta runtime pero ayuda al IDE y a mypy.
  • Union types modernos: float | None (Python 3.10+) — antes era Optional[float].
  • F-string self-documenting: f"{x=}" imprime x=valor — útil para debug.
  • repr vs str: {valor!r} usa repr() (con comillas para strings).
  • Format specs:
    • :.2f — 2 decimales
    • :, — separador de miles
    • :.1% — porcentaje con 1 decimal
    • :>10, :<10, :^10 — alineación con padding de 10

Para experimentar

  1. Agregá un complex (2+3j) y un bytes (b"hola") y mostrá su tipo.
  2. Probá int("3.14") y observá el error — ¿por qué falla?
  3. Usá type() para mostrar el tipo de True; notá que es subclase de int.
  4. Probá bool("False") — ¿qué devuelve y por qué?
  5. Combiná format specs: f"{3.14:>10.2f}" — alineado derecha con 2 decimales.
