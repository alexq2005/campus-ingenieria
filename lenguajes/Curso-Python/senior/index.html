8 módulos Internals · Performance Python 3.14 · free-threading uv · ruff · ty

📖 Para quién es

Para el que ya escribe Python que funciona y ahora necesita responder por qué funciona: por qué agregar hilos no aceleró nada, por qué el proceso consume 6 GB, por qué el __del__ no se ejecutó cuando esperaba, o si conviene bajar a Rust.

Pre-requisito real: el Curso de Python completo (M00–M14). Este track asume que POO, decoradores, generadores, concurrencia básica y la biblioteca estándar ya no te sorprenden.

Qué lo hace distinto del curso base: cada módulo explica internals de verdad, trae código medible, tablas de trade-offs con su costo, un worked example que razona una decisión real de ingeniería, y —lo más importante— cuándo NO hacer las cosas que enseña.

⚙️ Actualizado a septiembre de 2026. El ecosistema de Python cambió más en dos años que en los quince anteriores: el free-threading (sin GIL) pasó a ser oficialmente soportado en 3.14 con el PEP 779, y uv + ruff desplazaron a pip, poetry, pyenv, black, flake8 e isort. Este track enseña ese Python, no el de 2023.
