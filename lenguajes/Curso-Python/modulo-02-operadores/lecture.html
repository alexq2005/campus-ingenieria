Operadores de comparación

Devuelven bool:

3 == 3.0       # True (compara valor, no tipo)

Comparación encadenada

edad = 25

Operadores lógicos

OperadorSignificado
andY lógico
orO lógico
notNegación

Short-circuit evaluation

  • and devuelve el primer falsy o el último valor
  • or devuelve el primer truthy o el último valor
True and "hola"    # 'hola'
False and "hola"   # False
None or "default"  # 'default' (patrón común para defaults)
0 or 42            # 42

Operador walrus := (Python 3.8+)

Asigna y devuelve en una expresión:

# Sin walrus
linea = input()
while linea != "fin":
    print(linea)
    linea = input()

# Con walrus
while (linea := input()) != "fin":
    print(linea)

Operadores de identidad y pertenencia

a = [1, 2, 3]
b = [1, 2, 3]
c = a

a == b     # True (mismo contenido)
a is b     # False (objetos distintos)
a is c     # True (misma referencia)
a is None  # patrón estándar para chequeo None

3 in a         # True
4 in a         # False
"o" in "hola"  # True
Regla: usá is solo con None, True, False. Para igualdad de valor, ==.

Operadores bitwise

0b1100 & 0b1010   # 0b1000 = 8

1 << 4            # 16 (potencia de 2)

Operadores de asignación compuesta

x = 10
x += 5    # x = x + 5
x -= 2    # x = x - 2
x *= 3    # x = x * 3
x //= 2   # x = x // 2
x **= 2   # x = x ** 2
x %= 7    # x = x % 7

Precedencia (de mayor a menor)

  1. () — paréntesis
  2. ** — exponenciación
  3. +x, -x, ~x — unarios
  4. *, /, //, %
  5. +, -
  6. <<, >>
  7. &
  8. ^
  9. |
  10. ==, !=, <, >, <=, >=, is, in
  11. not
  12. and
  13. or
Regla: cuando dudes, usá paréntesis. La claridad vale más que la brevedad.

Respondé sin mirar arriba. Cada pregunta te explica el porqué.

1. ¿Qué devuelve la expresión 0 or 42?

Los operadores lógicos hacen short-circuit y devuelven un valor, no un bool: or devuelve el primer truthy (o el último valor). Como 0 es falsy, sigue y devuelve 42. Por eso None or "default" es el patrón clásico de valor por defecto.

2. Con a = [1, 2, 3] y b = [1, 2, 3], ¿qué devuelve a is b?

is compara identidad (si son el mismo objeto en memoria), no contenido. Son dos listas distintas: a == b da True pero a is b da False. Reservá is para None, True y False.

3. ¿Qué devuelve 4 / 2 en Python 3?

/ es división real y siempre devuelve float, aunque la división sea exacta. Si querés el entero, usá //: 4 // 2 da 2.
