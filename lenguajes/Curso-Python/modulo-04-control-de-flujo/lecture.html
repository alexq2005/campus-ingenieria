Módulo 04 — Control de Flujo

Indentación

Python usa indentación significativa. No hay {}. Todos los bloques se delimitan con sangría consistente (4 espacios — convención PEP 8).

if condicion:
    hacer_esto()       # dentro del if
    y_esto()           # dentro del if
hacer_otra_cosa()      # fuera del if
Mezclar tabs y espacios = error. Configurá tu editor para insertar 4 espacios al pulsar Tab.

Condicionales if / elif / else

edad = 18

if edad < 13:
    categoria = "niño"
elif edad < 18:
    categoria = "adolescente"
elif edad < 65:
    categoria = "adulto"
else:
    categoria = "mayor"

Operador ternario

estado = "mayor" if edad >= 18 else "menor"

match / case (Python 3.10+)

Pattern matching, equivalente avanzado a switch:

def describir(x):
    match x:
        case 0:
            return "cero"
        case int() if x > 0:
            return "positivo"
        case int():
            return "negativo"
        case [a, b]:
            return f"par {a}, {b}"
        case {"tipo": "circulo", "radio": r}:
            return f"círculo de radio {r}"
        case _:
            return "desconocido"

Bucle for

Itera sobre cualquier iterable (lista, tupla, dict, str, range, generador, archivo, etc.):

for fruta in ["manzana", "pera", "uva"]:
    print(fruta)

for i in range(5):           # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 10, 2):    # 2, 4, 6, 8 (start, stop, step)
    print(i)

for letra in "hola":
    print(letra)

for clave, valor in {"a": 1, "b": 2}.items():
    print(f"{clave}={valor}")

enumerate — índice + valor

for i, fruta in enumerate(frutas):
    print(f"{i}: {fruta}")

for i, fruta in enumerate(frutas, start=1):
    print(f"{i}: {fruta}")  # arranca en 1

zip — iterar varios al mismo tiempo

nombres = ["Ana", "Luis", "Eva"]
edades = [30, 25, 40]
for nombre, edad in zip(nombres, edades):
    print(f"{nombre} tiene {edad}")

Bucle while

contador = 0
while contador < 5:
    print(contador)
    contador += 1
Cuidado: si la condición nunca se hace falsa, bucle infinito. Asegurate que algo dentro modifique la condición.

while True con break

Patrón común para bucles "hasta que se cumpla algo":

while True:
    respuesta = input("¿Salir? (s/n): ")
    if respuesta == "s":
        break

break y continue

for i in range(10):
    if i == 3:
        continue        # salta esta iteración
    if i == 7:
        break           # sale del bucle
    print(i)
# Imprime: 0 1 2 4 5 6

else en bucles

Se ejecuta si el bucle terminó sin break:

for n in [2, 4, 6, 8]:
    if n % 2 != 0:
        print("Hay un impar")
        break
else:
    print("Todos pares")  # se ejecuta solo si no hubo break

Comprehensions (forma compacta de bucles)

List

cuadrados = [x**2 for x in range(10)]
pares = [x for x in range(20) if x % 2 == 0]
combinados = [(x, y) for x in [1,2,3] for y in ["a","b"]]

Dict

cuadrados = {n: n**2 for n in range(5)}
filtrado = {k: v for k, v in datos.items() if v > 0}

Set

unicos = {x % 3 for x in range(20)}

Generator (lazy, no construye lista en memoria)

suma = sum(x**2 for x in range(1_000_000))   # eficiente en memoria
Regla: si la comprehension tiene más de 1 if o 2 for, escribilo como bucle normal — legibilidad > brevedad.

pass — placeholder

Cuando necesitás un bloque sintácticamente pero todavía no escribiste el código:

def funcion_pendiente():
    pass

if edad < 18:
    pass  # TODO: validar consentimiento

Errores típicos con el control de flujo

1. Mezclar tabs y espacios — el código se ve alineado en pantalla y Python lo rechaza igual, porque para el intérprete un tab y cuatro espacios no son lo mismo. 
if x:
    hacer_esto()      # 4 espacios
	hacer_aquello()   # un TAB → ❌ TabError / IndentationError
Configurá el editor en "insertar espacios" con Tab = 4, y activá los caracteres invisibles cuando algo no cierre.
2. Un while cuya condición nunca cambia — el clásico bucle infinito. 
contador = 0
while contador < 5:
    print(contador)      # ❌ nadie toca contador: imprime 0 para siempre

contador = 0
while contador < 5:
    print(contador)
    contador += 1        # ✅ el paso que hace avanzar la condición
3. Encadenar if sueltos donde iba elif — las condiciones se solapan y gana la última que se cumple. 
edad = 10
if edad < 13:
    categoria = "niño"
if edad < 18:            # ❌ también es True: pisa el valor anterior
    categoria = "adolescente"
# categoria == "adolescente" para un chico de 10 años

if edad < 13:
    categoria = "niño"
elif edad < 18:          # ✅ solo se evalúa si el anterior dio False
    categoria = "adolescente"
4. Modificar la variable del for esperando saltear iteraciones. 
for i in range(10):
    if i % 2 == 0:
        i += 1        # ❌ no hace nada: la próxima vuelta i se reasigna desde el range

for i in range(1, 10, 2):   # ✅ cambiá el iterable...
    ...

i = 0
while i < 10:               # ✅ ...o usá un while si necesitás controlar el paso
    i += 2

Checkpoint — ¿lo tenés claro?

¿Cómo elegís entre for y while?

Usás for cuando sabés sobre qué vas a iterar: una lista, un rango, las líneas de un archivo. El bucle termina porque el iterable se agota, así que no existe el riesgo de olvidarte el paso. Usás while cuando lo que sabés es hasta cuándo: repetís mientras se cumpla una condición y no tenés de antemano la cantidad de vueltas (leer entradas del usuario, reintentar una conexión). Señal de alarma: si te encontrás llevando un contador a mano dentro de un while, casi seguro querías un for.

¿Por qué se prefiere enumerate(lista) antes que for i in range(len(lista))?

Porque range(len(...)) te da solo el índice y te obliga a escribir lista[i] cada vez que querés el valor: más ruido visual, más lugares donde equivocarte con el índice, y encima solo funciona sobre cosas indexables. enumerate te devuelve directamente el par (índice, valor), sirve para cualquier iterable y deja explícito que te interesan las dos cosas. Y si el índice no te importa, la respuesta correcta no es ninguna de las dos: es for elemento in lista.

¿Qué diferencia hay entre [x**2 for x in range(1_000_000)] y (x**2 for x in range(1_000_000))?

Los corchetes construyen la lista entera en memoria antes de seguir: un millón de enteros guardados aunque solo los vayas a sumar. Los paréntesis crean un generador, que no calcula nada hasta que se lo piden y produce un valor por vez; por eso sum(x**2 for x in range(1_000_000)) usa memoria constante. La contra del generador es que se consume una sola vez y no podés indexarlo ni pedirle len(): si necesitás recorrer el resultado dos veces, te conviene la lista.

🧠 Autoevaluación rápida

Respondé sin mirar arriba. Cada pregunta te explica el porqué.

1. El bloque else de un for se ejecuta…

El else de un bucle es "terminé de recorrer todo y nunca corté". Si en algún momento se ejecuta un break, el else se saltea. Es ideal para búsquedas: si no encontraste nada, el else avisa.

2. ¿Qué valores recorre for i in range(2, 10, 2)?

range(start, stop, step): arranca en 2, salta de a 2 y nunca incluye el stop. Por eso llega hasta 8 y no hasta 10.

3. ¿Qué imprime este bucle?
for i in range(10): si i == 3 → continue; si i == 7 → break; print(i)

continue saltea esa iteración (por eso falta el 3) y sigue con la siguiente. break corta el bucle entero antes de imprimir, así que el 7 tampoco aparece.
