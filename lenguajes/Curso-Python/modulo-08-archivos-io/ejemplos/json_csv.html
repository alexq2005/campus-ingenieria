json_csv.py — Conversión CSV ↔ JSON

Pipeline completo de transformación: escribe un CSV demo, lo lee con csv.DictReader, convierte edad a entero, y guarda el resultado como JSON formateado.

Cómo ejecutar

python json_csv.py

# El script genera 2 archivos en su mismo directorio:
ls -la
# personas.csv    (intermedio)
# personas.json   (resultado)

Código fuente

⬇ Descargar .py 
"""Ejemplo: leer CSV, transformar y escribir JSON."""

import csv
import json
from pathlib import Path

CSV_DEMO = """nombre,edad,ciudad
Ana,30,Buenos Aires
Luis,25,Córdoba
Eva,40,Rosario
"""


def main() -> None:
    base = Path(__file__).parent
    csv_path = base / "personas.csv"
    json_path = base / "personas.json"

    csv_path.write_text(CSV_DEMO, encoding="utf-8")

    personas: list[dict] = []
    with csv_path.open(encoding="utf-8", newline="") as f:
        for fila in csv.DictReader(f):
            fila["edad"] = int(fila["edad"])
            personas.append(fila)

    json_path.write_text(
        json.dumps(personas, indent=2, ensure_ascii=False),
        encoding="utf-8",
    )

    print(f"Convertidas {len(personas)} personas → {json_path}")


if __name__ == "__main__":
    main()

Conceptos clave

  • pathlib: Path(__file__).parent — directorio donde vive el script (no del que lo ejecuta).
  • csv.DictReader: parsea CSV usando la primera fila como header. Cada fila es un dict.
  • Type cast manual: CSV es texto puro; edad llega como "30". Convertir explícitamente con int().
  • newline="": importante en Windows para evitar líneas en blanco extra entre filas.
  • ensure_ascii=False: permite caracteres unicode (acentos) sin escapar a \uXXXX.
  • indent=2: pretty-print del JSON.

Ejercicios para extenderlo

  1. Hacer la conversión inversa: leer el JSON y volver a generar CSV con csv.DictWriter.
  2. Agregar validación: si edad no es numérico, loguear warning y saltear esa fila.
  3. Aceptar archivos custom con argparse: python json_csv.py input.csv output.json.
  4. Manejar errores: archivo inexistente (FileNotFoundError), CSV mal formado.
  5. Soportar formato YAML adicional con la librería pyyaml.
