El track experto. Go es fácil de escribir y difícil de operar bien: esto es lo segundo.
"Lanzar una goroutine es trivial. Entender qué hace el runtime con ella es el trabajo."

8 módulos Scheduler GMP · GC Go 1.26 · Green Tea pprof · Producción

📖 Para quién es

Para el que ya escribe Go y ahora necesita responder por qué: por qué la memoria crece hasta que el proceso muere, por qué el servicio se cae en cascada cuando su dependencia se pone lenta, por qué el pod recibe OOMKill si el heap está bien, o si conviene un mutex o un canal.

Pre-requisito real: el Curso de Go completo (M00–M12). Goroutines, canales, interfaces y errores como valores tienen que estar cómodos.

Qué lo hace distinto: cada módulo abre el runtime, trae código medible con benchstat y pprof, tablas de trade-offs con su costo, y un worked example que resuelve un diagnóstico real de producción.

⚙️ Actualizado a septiembre de 2026. El GC Green Tea es el default desde Go 1.26 —entre 10% y 40% menos overhead de GC— y el escape hatch al recolector anterior desaparece en 1.27. El track también cubre new con expresiones, genéricos auto-referenciales, SIMD experimental y el GOMAXPROCS consciente de cgroups.
