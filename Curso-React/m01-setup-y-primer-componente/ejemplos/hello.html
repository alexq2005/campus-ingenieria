hello.jsx — Primer componente React

Tu primer componente React. Demuestra JSX, props, destructuring, expresiones JavaScript dentro del markup, y reuso del mismo componente con datos distintos.

¿Qué hace?

  • Define un componente Saludo que recibe props nombre y edad.
  • Calcula derivadamente si es mayor de edad (sin guardarlo en estado).
  • Renderiza una tarjeta con estilos inline (style como objeto).
  • El App usa Saludo 3 veces con datos diferentes.

Cómo ejecutarlo

# 1) Crear un proyecto Vite si no tenés (solo la primera vez)
npm create vite@latest mi-app -- --template react
cd mi-app
npm install

# 2) Reemplazar src/App.jsx con el contenido de hello.jsx
# (lo que está abajo)

# 3) Correr el dev server
npm run dev
# Abrir http://localhost:5173
Si no querés instalar nada local, abrí stackblitz.com/fork/react, pegá el código en App.jsx y va a correr al instante.

Código fuente

⬇ Descargar .jsx 🔗 Ver crudo 
// hello.jsx — Primer componente React.
// Demuestra: JSX, función componente, props, expresiones JS dentro de JSX.

function Saludo({ nombre, edad }) {
  const esMayor = edad >= 18;

  return (
    <div className="tarjeta" style={{
      border: '1px solid #61dafb',
      borderRadius: 8,
      padding: 16,
      maxWidth: 300,
      fontFamily: 'system-ui, sans-serif',
    }}>
      <h2>Hola, {nombre} 👋</h2>
      <p>Edad: <strong>{edad}</strong></p>
      <p>Estado: {esMayor ? '✅ Mayor de edad' : '🚸 Menor de edad'}</p>
      <p>Año aproximado de nacimiento: {2026 - edad}</p>
    </div>
  );
}

// App raíz: usa Saludo 3 veces con props distintas
export default function App() {
  return (
    <main style={{ padding: 24, display: 'flex', gap: 16, flexWrap: 'wrap' }}>
      <h1>Hello World — React</h1>
      <div style={{ display: 'flex', gap: 16, flexWrap: 'wrap' }}>
        <Saludo nombre="Ana" edad={30} />
        <Saludo nombre="Luis" edad={17} />
        <Saludo nombre="Eva" edad={45} />
      </div>
    </main>
  );
}

Conceptos del ejemplo

  • Destructuring de props: function Saludo({ nombre, edad }).
  • Valor derivado: esMayor NO es estado — se calcula en cada render desde edad.
  • Estilos inline: objeto JS, camelCase (borderRadius, no border-radius).
  • Expresiones en JSX: {nombre}, {2026 - edad}, {cond ? a : b}.
  • Componente reutilizado: 3 instancias con props distintas.

Variantes para probar

  1. Agregá una prop hobbies: string[] y renderizá la lista con .join(', ').
  2. Cambiá el color del borde según si es mayor de edad (rojo/verde).
  3. Extraé los estilos a un archivo CSS y usá className.
  4. Agregá un 4º Saludo con edad 0 y mostrá "Recién nacido".
