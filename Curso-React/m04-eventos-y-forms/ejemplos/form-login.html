form-login.jsx — Form controlado con validación

Formulario de login completo con email, password y checkbox. Validación en vivo, errores específicos, botón deshabilitado, submit async simulado, mensaje de resultado.

¿Qué demuestra?

  • 3 inputs controlados: email (text), password (password), acepta (checkbox).
  • Validaciones derivadas: regex de email, longitud pwd, contiene número — TODAS calculadas en render, no en estado.
  • Mensajes de error progresivos: solo se muestran después de que el user empezó a escribir.
  • Botón disabled hasta que el form sea válido + estado de carga.
  • Submit async simulado con setTimeout.
  • Panel debug con JSON.stringify del estado completo.

Cómo ejecutarlo

npm run dev

// form-login.jsx — Form controlado con validación en vivo.
// Demuestra: inputs controlados, validación derivada, mensajes de error,
//            botón disabled, submit con preventDefault, estado de loading.

import { useState } from 'react';

export default function App() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [acepta, setAcepta] = useState(false);
  const [enviando, setEnviando] = useState(false);
  const [resultado, setResultado] = useState(null);

  // Validaciones derivadas (no en useState)
  const emailValido = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
  const pwdLargaSuficiente = password.length >= 8;
  const pwdConNumero = /\d/.test(password);
  const pwdValida = pwdLargaSuficiente && pwdConNumero;
  const formValido = emailValido && pwdValida && acepta;

  async function handleSubmit(e) {
    e.preventDefault();           // ⭐ evitar reload del browser
    setEnviando(true);
    setResultado(null);

    // Simular request async
    await new Promise(r => setTimeout(r, 1000));

    setResultado({ tipo: 'ok', mensaje: `Bienvenido, ${email}` });
    setEnviando(false);
  }

  // ... (resto del JSX, ver archivo completo)
}

Lecciones clave del ejemplo

  • Patrón controlado canónico: value={x} + onChange={e => setX(e.target.value)}.
  • Checkbox usa checked, no value. Y e.target.checked en lugar de .value.
  • Validaciones SOLO mostrar tras user input: {email && !emailValido && ...}. No spamear errores al renderizar inicial.
  • preventDefault es obligatorio en submit — sin él, la página recarga.
  • Estado de loading: enviando deshabilita el botón mientras la request va.

Errores típicos a evitar

  • ❌ onClick={handleSubmit()} — ejecuta al render, no al click.
  • ❌ Olvidar e.preventDefault() → la página recarga, perdés estado.
  • ❌ value={x} sin onChange → input readonly + warning.
  • ❌ Guardar emailValido en useState — el setEffect duplica trabajo y desincroniza.
