lista-tareas.jsx — CRUD con listas e immutability

To-do list completo con agregar/togglear/eliminar tareas, filtros (todas/pendientes/hechas), conditional rendering y limpiar completadas. Demuestra el patrón canónico de listas en React.

¿Qué demuestra?

  • Keys estables: crypto.randomUUID() al crear, NO el index.
  • Agregar sin push: [...prev, nuevo].
  • Toggle con map: devolver nuevo array donde solo cambia el matching.
  • Eliminar con filter: devolver nuevo array sin el item.
  • Conditional rendering: estado vacío, items, botones según condición.
  • Enter para agregar: onKeyDown capturando key.
  • Pluralización: {n} pendiente{n !== 1 && 's'}.

// lista-tareas.jsx — CRUD completo con listas, keys e immutability.

import { useState } from 'react';

export default function App() {
  const [tareas, setTareas] = useState([
    { id: crypto.randomUUID(), texto: 'Aprender React', hecha: true },
    { id: crypto.randomUUID(), texto: 'Practicar useState', hecha: false },
    { id: crypto.randomUUID(), texto: 'Construir mi capstone', hecha: false },
  ]);

  const [nueva, setNueva] = useState('');
  const [filtro, setFiltro] = useState('todas');

  // Filtrar SIN mutar
  const visibles = tareas.filter(t => {
    if (filtro === 'pendientes') return !t.hecha;
    if (filtro === 'hechas') return t.hecha;
    return true;
  });

  function agregar() {
    const texto = nueva.trim();
    if (!texto) return;
    setTareas(prev => [
      ...prev,
      { id: crypto.randomUUID(), texto, hecha: false },
    ]);
    setNueva('');
  }

  function toggle(id) {
    setTareas(prev => prev.map(t =>
      t.id === id ? { ...t, hecha: !t.hecha } : t
    ));
  }

  function eliminar(id) {
    setTareas(prev => prev.filter(t => t.id !== id));
  }

  // ... resto del JSX en el archivo descargable
}

Los 3 patrones canónicos de actualización

OperaciónMétodoPor qué
Agregar[...prev, nuevo]Spread crea NUEVO array
Quitarprev.filter(x => x.id !== id)filter devuelve nuevo array
Actualizar unoprev.map(x => x.id === id ? {...x, ...cambios} : x)map devuelve nuevo array
Ordenar[...prev].sort(...)Spread primero porque sort muta
NUNCA tareas.push(x); setTareas(tareas) — la referencia es la MISMA, React no detecta cambio, no re-renderiza.
