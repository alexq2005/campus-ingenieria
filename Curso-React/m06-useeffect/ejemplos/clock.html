clock.jsx — useEffect con timer + listeners + cleanup

Demuestra los 4 usos canónicos de useEffect: timer (setInterval), listener de window (resize), browser API (online/offline), y sincronización con document (title). TODOS con cleanup correcto.

¿Qué demuestra?

  • useEffect(fn, []) — corre solo al montar.
  • useEffect(fn, [hora]) — re-corre cuando hora cambia.
  • Cleanup function: return () => clearInterval(id).
  • Sin cleanup → leaks (listeners zombies, timers que siguen).
  • En dev con StrictMode: el cleanup se llama 2 veces para detectar bugs.

Cómo ejecutarlo

npm run dev
# Reemplazá src/App.jsx
# Abrí DevTools console para ver los logs del cleanup

Código fuente

⬇ Descargar .jsx 🔗 Ver crudo 
// clock.jsx — useEffect con cleanup, listeners y timer.

import { useState, useEffect } from 'react';

export default function App() {
  const [hora, setHora] = useState(new Date());
  const [width, setWidth] = useState(window.innerWidth);
  const [online, setOnline] = useState(navigator.onLine);

  // ─── Effect 1: timer con cleanup ───
  useEffect(() => {
    console.log('⏰ Iniciando timer');
    const id = setInterval(() => setHora(new Date()), 1000);
    return () => {
      console.log('⏰ Cancelando timer');
      clearInterval(id);
    };
  }, []);

  // ─── Effect 2: resize listener con cleanup ───
  useEffect(() => {
    function handleResize() { setWidth(window.innerWidth); }
    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);

  // ─── Effect 3: online/offline ───
  useEffect(() => {
    function onConnect() { setOnline(true); }
    function onDisconnect() { setOnline(false); }
    window.addEventListener('online', onConnect);
    window.addEventListener('offline', onDisconnect);
    return () => {
      window.removeEventListener('online', onConnect);
      window.removeEventListener('offline', onDisconnect);
    };
  }, []);

  // ─── Effect 4: sincronizar title del documento ───
  useEffect(() => {
    document.title = `${hora.toLocaleTimeString()} — Clock`;
    return () => { document.title = 'App'; };
  }, [hora]);

  return (
    // ... JSX en el archivo completo
  );
}

Por qué cleanup es OBLIGATORIO

Sin cleanupConsecuencia
setInterval sin clearIntervalTimer sigue corriendo tras desmontar → "no podés setear estado de componente desmontado"
addEventListener sin removeEventListenerCada mount agrega otro listener → cientos zombies al navegar
WebSocket sin closeConexión sigue activa → memory leak en server
fetch sin AbortControllerRace condition al desmontar antes del response
Regla simple: si tu effect "prende" algo (listener, timer, subscription), el cleanup debe "apagarlo".

StrictMode y doble-mount en dev

Cuando ejecutes esto en dev verás "Iniciando timer" + "Cancelando timer" + "Iniciando timer" en console. Es esperado: React 18+ con StrictMode monta-desmonta tu componente DOS veces para detectar effects sin cleanup. En producción solo corre 1 vez.

Variantes para probar

  2. Cambiar intervalo dinámicamente (cada 1s, 5s, 10s) usando [intervalo] como dep.
  3. Agregar countdown desde N segundos a 0.
  4. Mostrar tiempo desde último click (resetea al click).
