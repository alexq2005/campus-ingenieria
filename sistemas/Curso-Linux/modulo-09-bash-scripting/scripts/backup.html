backup.sh — Backup con timestamp y rotación

Script bash que comprime un directorio en .tar.gz con timestamp, valida argumentos, hace cleanup ante interrupción y rota backups viejos manteniendo solo los últimos 7.

¿Qué hace?

  • Valida que reciba al menos 1 argumento (directorio origen).
  • Acepta destino opcional (default ~/backups).
  • Genera nombre con timestamp YYYYMMDD-HHMMSS.
  • Usa trap para limpiar archivo parcial si lo interrumpís con Ctrl+C.
  • Rota: borra backups más viejos que los 7 más recientes con el mismo prefijo.

Cómo ejecutar

# 1) Hacerlo ejecutable
chmod +x backup.sh

# 2) Backup a destino default (~/backups)
./backup.sh /home/ana/proyectos

# 3) Backup con destino custom
./backup.sh /var/www /mnt/backups

# 4) Probar con un directorio chico primero
mkdir -p /tmp/prueba && echo "hola" > /tmp/prueba/test.txt
./backup.sh /tmp/prueba /tmp/backups
Para automatizarlo: crear un timer systemd o entrada de cron diaria que llame a este script. Ver Módulos 10 y 12.

Código fuente

⬇ Descargar .sh 
#!/usr/bin/env bash
# Backup script — comprime un directorio con timestamp.
# Uso: ./backup.sh <directorio_origen> [destino]

set -euo pipefail

# --- Validación de argumentos ---
if [[ $# -lt 1 ]]; then
    echo "Uso: $0 <directorio_origen> [destino]" >&2
    exit 1
fi

ORIGEN="${1%/}"   # quita barra final si la hay
DESTINO="${2:-$HOME/backups}"

if [[ ! -d "$ORIGEN" ]]; then
    echo "Error: '$ORIGEN' no es un directorio válido" >&2
    exit 1
fi

# --- Preparación ---
mkdir -p "$DESTINO"
TIMESTAMP=$(date +%Y%m%d-%H%M%S)
NOMBRE=$(basename "$ORIGEN")
ARCHIVO="$DESTINO/${NOMBRE}-${TIMESTAMP}.tar.gz"

# --- Cleanup en caso de interrupción ---
limpiar() {
    if [[ -f "$ARCHIVO" && ! -s "$ARCHIVO" ]]; then
        echo "Backup interrumpido, eliminando archivo parcial..." >&2
        rm -f "$ARCHIVO"
    fi
}
trap limpiar INT TERM

# --- Backup ---
echo "📦 Comprimiendo '$ORIGEN' → '$ARCHIVO'"
tar -czf "$ARCHIVO" -C "$(dirname "$ORIGEN")" "$NOMBRE"

# --- Reporte ---
TAMANO=$(du -h "$ARCHIVO" | cut -f1)
echo "✅ Backup creado: $ARCHIVO ($TAMANO)"

# --- Rotación: mantener últimos 7 ---
cd "$DESTINO"
mapfile -t VIEJOS < <(ls -1t "${NOMBRE}-"*.tar.gz 2>/dev/null | tail -n +8)
for f in "${VIEJOS[@]}"; do
    echo "🗑️  Eliminando viejo: $f"
    rm -f "$f"
done

Conceptos clave del script

  • ${1%/} — Parameter expansion: quita el último / si existe.
  • ${2:-$HOME/backups} — Default value si $2 está vacío.
  • trap limpiar INT TERM — Ejecuta función al recibir Ctrl+C (INT) o TERM.
  • tar -czf ARCHIVO -C dir nombre — -C cambia directorio antes de tar; evita rutas absolutas en el archivo.
  • mapfile -t VIEJOS < <(comando) — Process substitution: lee output de un comando en un array línea por línea.
  • ls -1t | tail -n +8 — Lista por fecha desc; tail -n +8 deja todo desde la línea 8 en adelante (los "viejos").

Ejercicios para extenderlo

  1. Agregar opción --exclude PATRON para pasar a tar --exclude.
  2. Verificar integridad después de crear: tar -tzf ARCHIVO > /dev/null.
  3. Sumar SHA-256 al lado: sha256sum ARCHIVO > ARCHIVO.sha256.
  4. Soportar destino remoto vía rsync o scp.
  5. Hacer la cantidad de backups a mantener configurable con env var BACKUP_KEEP.
