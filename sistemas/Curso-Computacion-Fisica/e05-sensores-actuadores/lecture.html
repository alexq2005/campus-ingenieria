E05 — Sensores y Actuadores

"Un sistema embebido sin sensores es ciego; sin actuadores, es paralítico. Con ambos, percibe y cambia el mundo." — la definición de computación física
Acá se cierra el ciclo de la computación física: sensar (traducir el mundo a números) y actuar (traducir números a movimiento, luz, sonido). Es la membrana entre tu código y la realidad.
🔗 El loop completo: sensor → ADC (E03) → tu código decide → actuador. Es el ciclo sensar-decidir-actuar que viste en el proyecto del robot, y el espejo físico de "percepción → modelo → acción" de la IA (M39).

Parte 1 — Sensores: leer el mundo

🔗 Cada categoría usa una técnica distinta que ya viste: digital simple (E03 GPIO), analógico (E03 ADC), bus (E03 I2C/SPI), pulso (E04 timers/input capture). E05 es donde APLICÁS todo lo anterior a componentes reales.

2. Acondicionamiento de señal

La señal cruda de un sensor casi nunca está lista para el ADC: puede ser muy débil, tener ruido, o estar fuera de rango. Acondicionar = adaptarla (amplificar, filtrar, escalar) antes de digitalizar.
  • Divisor de voltaje (E01): para sensores resistivos (LDR, termistor).
  • Amplificación (op-amp, E01): señales débiles (micrófono, célula de carga).
  • Filtrado (capacitor, E01): quitar ruido de alta frecuencia.
  • Filtro en software: promediar N lecturas, media móvil — el primer paso del DSP (E07).
// Filtro simple en software: media móvil
float suavizar(float nueva) {
  static float prom = 0;
  prom = prom * 0.9 + nueva * 0.1;   // 90% histórico, 10% nuevo
  return prom;
}
🔗 Ese filtro de media móvil es un filtro pasa-bajos digital — el caso más simple del DSP que profundiza E07, y conecta con cómo se preprocesan datos para ML (M39). Limpiar la señal ANTES de procesarla es universal: en hardware con un capacitor, en software con un promedio.

Parte 2 — Actuadores: cambiar el mundo

3. LED y cargas pequeñas

Un LED o una carga <20mA se controla directo desde un GPIO + resistencia (E00). Para tiras de LED, motores o relés, NO — necesitás un transistor (E01).

4. Motores DC

Giran al aplicar voltaje; la velocidad depende del voltaje (PWM) y la dirección de la polaridad. Piden cientos de mA → driver obligatorio (L298N, L9110, DRV8833).
// Driver L298N: IN1/IN2 dan dirección, ENA (PWM) da velocidad
void motor(int velocidad, bool adelante) {
  digitalWrite(IN1, adelante);
  digitalWrite(IN2, !adelante);
  analogWrite(ENA, velocidad);   // 0-255 PWM (E03)
}
El motor es un inductor → genera picos al frenar/invertir. El driver incluye diodos flyback (E01), pero si armás tu propio circuito, NO los olvides o quemás todo.

5. Servomotores

Un servo se posiciona en un ángulo exacto (0-180°) según el ancho de un pulso PWM. Ideal para brazos robóticos, dirección, cámaras móviles.
#include <ESP32Servo.h>
Servo s;
void setup() { s.attach(13); }
void loop() {
  s.write(0);    delay(1000);   // posición 0°
  s.write(90);   delay(1000);   // 90°
  s.write(180);  delay(1000);   // 180°
}

6. Motores paso a paso (stepper)

Se mueven en "pasos" discretos exactos (ej 1.8°/paso = 200 pasos/vuelta). Posicionamiento preciso sin sensor de realimentación. Usados en impresoras 3D, CNC, cámaras.

7. Relés — controlar alta tensión

Un relé es un interruptor electromecánico: el MCU (señal de 3.3V) controla un circuito de ALTA potencia (220V, electrodomésticos) sin contacto eléctrico directo. Aislación = seguridad.
⚠️ 220V mata. Trabajar con relés a tensión de red requiere conocimiento y precauciones reales. Para aprender, practicá con cargas de bajo voltaje (una lámpara LED de 5V). El 220V no es para experimentar sin supervisión.
🔗 El relé es el límite de este curso-puente: del otro lado está la EE de potencia (máquinas eléctricas, alta tensión) que NO se anida con software y queda fuera de scope. Computación física llega hasta "controlar potencia con una señal lógica" — el resto es ingeniería eléctrica pura.

8. Otros actuadores

  • Buzzer / parlante: sonido vía PWM (frecuencia = tono).
  • Pantallas: OLED (I2C), LCD, e-paper, tiras LED direccionables (WS2812/NeoPixel).
  • Bombas, válvulas, electroimanes: cargas inductivas vía transistor/relé + diodo flyback.

9. El ciclo completo: ejemplo termostato

void loop() {
  float temp = leerSensor();              // SENSAR (E03 ADC + E05 sensor)
  float suave = suavizar(temp);           // acondicionar (filtro software)

  if (suave < objetivo - 0.5) {           // DECIDIR
    digitalWrite(RELE_CALEFACTOR, HIGH);  // ACTUAR (E05 relé)
  } else if (suave > objetivo + 0.5) {
    digitalWrite(RELE_CALEFACTOR, LOW);
  }
  // la histéresis (±0.5) evita que prenda/apague sin parar
}
🔗 La histéresis (banda muerta para evitar oscilación) es un concepto de control que profundiza E08 (PID). Acá lo ves en su forma más simple: sin ella, el relé haría "clic-clic-clic" infinito cerca del umbral. Es el preludio del control de lazo cerrado.

10. Práctica

  • Wokwi — sensores y servos simulados.

🌡️ Simulador de histéresis — el termostato

La temperatura (naranja) oscila cerca del objetivo. Con 1 solo umbral el calefactor prende/apaga sin parar (chattering). Subí la banda de histéresis (2 umbrales) y mirá los toggles desplomarse.
Calefactor: OFF Cambios (toggles): 0 en los últimos ~8s
Con banda 0 (un umbral), el ruido hace que el calefactor cambie de estado decenas de veces — desgasta el relé y consume. Subí la banda: con 2 umbrales separados, el estado solo cambia al cruzar el umbral lejano.

11. Errores típicos

Alimentar motor/servo desde el pin del MCU: piden más corriente de la que el pin da → quema el chip. Fuente separada + driver.
GND no común entre MCU y driver/fuente: sin tierra compartida (E00), las señales no se interpretan. Siempre unir los GND.
Leer un sensor analógico sin filtrar: ruido → lecturas saltarinas. Promediar o filtrar (hardware o software).
Control sin histéresis: el actuador oscila (prende/apaga) sin parar cerca del umbral. Agregá banda muerta.
Relé sin entender el voltaje de la carga: 220V es peligroso. Practicar con bajo voltaje primero.

✅ Checkpoint

1. ¿Cuáles son las 4 formas de leer un sensor y qué técnica usa cada una?

Digital (digitalRead/GPIO), analógico (analogRead/ADC), bus I2C-SPI (protocolo + librería), y por pulso/tiempo (pulseIn/timer). Cada una aplica algo de E03/E04.

2. ¿Qué es acondicionar una señal y por qué hace falta?

Adaptar la señal cruda del sensor (amplificar, filtrar, escalar) antes de digitalizarla, porque suele ser débil, ruidosa o fuera de rango. Se hace con divisores, op-amps, capacitores (E01) o filtros en software.

3. ¿Por qué un motor necesita driver y el LED no?

Porque el motor pide cientos de mA y el pin del MCU da ~20mA — conectarlo directo quema el chip. El driver usa una fuente separada y recibe solo la señal de control. El LED, al consumir poco, va directo con una resistencia.

4. ¿Cómo se controla la posición de un servo?

Con el ancho de un pulso PWM: distintos anchos corresponden a distintos ángulos (0-180°). La librería Servo abstrae esto en s.write(angulo).

5. ¿Para qué sirve un relé y cuál es el riesgo?

Permite que una señal lógica de 3.3V controle un circuito de alta potencia (220V) con aislación eléctrica. El riesgo: la alta tensión es peligrosa; hay que practicar con bajo voltaje y tener precauciones reales con 220V.

6. ¿Qué es la histéresis y por qué importa en control?

Una banda muerta alrededor del umbral (ej ±0.5°) que evita que el actuador oscile prendiendo/apagando sin parar cuando la medición está cerca del objetivo. Es el preludio del control de lazo cerrado (E08/PID).

🧠 Autoevaluación rápida

Respondé sin mirar arriba. Cada pregunta te explica el porqué.

1. ¿Por qué un motor DC necesita un driver (L298N, DRV8833) y un LED no?

El driver alimenta el motor desde una fuente separada y del MCU solo recibe señales de control: IN1/IN2 para la dirección y PWM en ENA para la velocidad. Un LED consume poco, así que va directo al GPIO con su resistencia (E00).

2. ¿Cómo se le indica a un servo SG90 el ángulo al que tiene que posicionarse?

Cada ancho de pulso corresponde a un ángulo del rango 0-180°. La librería lo abstrae en s.write(angulo), pero por debajo sigue siendo PWM (E03). Los 3 cables del servo son alimentación, GND y esa señal.

3. En el termostato (if (suave < objetivo - 0.5) … else if (suave > objetivo + 0.5)), ¿qué problema resuelve la histéresis?

Con un solo umbral, el ruido lo cruza todo el tiempo y el actuador hace "clic-clic-clic" (chattering): desgasta el relé y desperdicia energía. Dos umbrales separados por una banda muerta estabilizan el control — es el preludio del lazo cerrado / PID de E08.
