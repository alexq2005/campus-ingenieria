Módulo 03 — Control de Flujo

Acá Go te sorprende de nuevo con su obsesión por la simplicidad: donde otros lenguajes tienen if, while, do-while, for y foreach, Go tiene if, un solo bucle for y un switch que no te traiciona. Menos cosas que aprender, menos formas de equivocarte. Vamos una por una.

if: sin paréntesis, con llaves obligatorias

El if de Go es como el de Python/JS en idea, pero con reglas estrictas de forma:

edad := 18

if edad >= 18 {
    fmt.Println("Mayor de edad")
} else if edad >= 13 {
    fmt.Println("Adolescente")
} else {
    fmt.Println("Niño")
}
📌 Dos reglas innegociables: la condición NO lleva paréntesis (if edad >= 18, no if (edad >= 18)), y las llaves { } son obligatorias siempre, incluso para una sola línea. Además, la llave de apertura { va en la misma línea que el if: si la ponés debajo, el código no compila.

if con sentencia de inicialización

Go te deja declarar una variable justo en el if, antes de la condición, separada por ;. Esa variable solo vive dentro del if/else:

if x := calcular(); x > 0 {
    fmt.Println("positivo:", x)
} else {
    fmt.Println("no positivo:", x)
}
// acá x ya NO existe
💡 Por qué es idiomático. En Go casi todo devuelve un valor y un error juntos. El patrón estrella es if err := hacerAlgo(); err != nil { ... }: ejecutás la función, capturás el error y lo chequeás en una sola línea, manteniendo err acotado a ese bloque. Vas a verlo en TODO el código Go (lo profundizamos en M07).

El único bucle: for

💡 Concepto central del módulo: Go tiene UN SOLO bucle, la palabra clave for. No existe while ni do-while. En vez de memorizar varios keywords, aprendés cuatro formas de escribir el mismo for. Esa es toda la repetición que el lenguaje te da... y alcanza para todo.

Forma 1 — clásica (init; condición; post)

Las tres partes de siempre: inicialización, condición y paso. Idéntica al for de C/Java, pero sin paréntesis:

for i := 0; i < 10; i++ {
    fmt.Println(i)   // imprime 0..9
}

Forma 2 — solo condición (hace de while)

Si dejás solo la condición, tenés el while de otros lenguajes:

n := 1
for n < 100 {        // mientras n < 100
    n = n * 2
}
fmt.Println(n)        // 128

Forma 3 — infinito (con break)

Sin nada después de for, el bucle es infinito. Salís con break (o return):

contador := 0
for {                 // forever
    contador++
    if contador == 5 {
        break         // corta el bucle
    }
}

Forma 4 — range (iterar colecciones)

range recorre slices, arrays, maps y strings. Devuelve dos valores: índice (o clave) y valor:

frutas := []string{"manzana", "pera", "kiwi"}

for i, v := range frutas {
    fmt.Println(i, v)   // 0 manzana / 1 pera / 2 kiwi
}

// Si no te interesa el índice, descartalo con _
for _, v := range frutas {
    fmt.Println(v)
}

// Solo el índice (omitís el segundo)
for i := range frutas {
    fmt.Println(i)
}
En un map, range devuelve (clave, valor) en vez de (índice, valor). En un string, devuelve (posición en bytes, rune) — útil para texto Unicode. Las colecciones las vemos a fondo en M04, acá lo importante es la forma del bucle.

switch: sin break, no cae al siguiente

El switch de Go corrige el error histórico de C: cada case termina solo. No necesitás escribir break al final de cada caso, y por defecto no "cae" (fall through) al siguiente:

switch dia {
case "sábado", "domingo":          // varios valores en un case
    fmt.Println("Finde 🎉")
case "lunes":
    fmt.Println("Arranca la semana")
default:
    fmt.Println("Día normal")
}
📌 Al revés que C/Java/JS. En esos lenguajes, si olvidás el break el caso "cae" al siguiente. En Go es al revés: el break es implícito. Si querés que caiga, lo pedís explícitamente con fallthrough. 
switch n {
case 1:
    fmt.Println("uno")
    fallthrough          // fuerza ejecutar TAMBIÉN el siguiente case
case 2:
    fmt.Println("dos")
}
// si n == 1, imprime "uno" Y "dos"

switch sin condición (como if-else encadenado)

Si no le ponés una variable al switch, cada case es una condición booleana. Es una forma más limpia de escribir un if / else if / else largo:

switch {                 // sin expresión
case nota >= 9:
    fmt.Println("Excelente")
case nota >= 7:
    fmt.Println("Aprobado")
default:
    fmt.Println("A recuperar")
}
Existe también el switch sobre tipos (switch v := x.(type) { ... }), que ramifica según el tipo dinámico de un valor. Necesita interfaces para tener sentido, así que lo vemos en M06.

break, continue y labels

  • break — corta el bucle (o el switch) actual.
  • continue — salta a la siguiente iteración del bucle, sin ejecutar lo que queda del cuerpo.
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue         // saltea los pares
    }
    fmt.Println(i)       // 1 3 5 7 9
}
🔗 Pensalo así: break es "me voy de la fila ya". continue es "esta persona no me interesa, paso a la que sigue". Sin abandonar la fila.

Para cortar o continuar un bucle externo desde uno anidado, Go usa labels (etiquetas). Es poco común, pero existe:

externo:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if i*j > 2 {
            break externo    // rompe el for de afuera, no solo el de adentro
        }
    }
}

Errores típicos viniendo de Python/JS

Buscar while. No existe en Go. Si necesitás un "mientras", usá la Forma 2: for condicion { }.
Olvidar que range devuelve DOS valores. for v := range frutas NO te da el valor: te da el índice. El valor es el segundo: for i, v := range frutas. Si solo querés el valor, usá for _, v := range frutas.
Esperar que el switch caiga al siguiente case. Viniendo de C/JS uno asume el fall-through automático. En Go cada case corta solo; si querés caer, escribí fallthrough.
Poner la { en la línea de abajo. En Go la llave de apertura va SIEMPRE en la misma línea que if/for/switch. Bajarla a la línea siguiente es un error de compilación (por cómo Go inserta el ; automático).

Ejemplo: las 4 formas de for + un switch idiomático

package main

import "fmt"

func main() {
    // Forma 1: clásica
    for i := 0; i < 3; i++ {
        fmt.Print(i, " ")
    }
    fmt.Println()                 // 0 1 2

    // Forma 2: como while
    n := 1
    for n < 10 {
        n *= 2
    }
    fmt.Println(n)                // 16

    // Forma 3: infinito + break
    pasos := 0
    for {
        pasos++
        if pasos == 3 {
            break
        }
    }
    fmt.Println(pasos)           // 3

    // Forma 4: range
    for i, letra := range "Go" {
        fmt.Println(i, string(letra))   // 0 G / 1 o
    }

    // switch idiomático (sin condición, sin break)
    nota := 8
    switch {
    case nota >= 9:
        fmt.Println("Excelente")
    case nota >= 7:
        fmt.Println("Aprobado")        // <- entra acá
    default:
        fmt.Println("A recuperar")
    }
}

Checkpoint — ¿lo tenés claro?

¿Cómo escribís un "while clásico" en Go si no existe la palabra while?

Con la Forma 2 del for: dejás solo la condición. Por ejemplo for n < 100 { n *= 2 } repite mientras n < 100. Es exactamente un while, pero con la palabra for.

En for i, v := range frutas, ¿qué es i y qué es v?

i es el índice (la posición, empezando en 0) y v es el valor en esa posición. Si no te interesa el índice, lo descartás con _: for _, v := range frutas. En un map, i pasa a ser la clave.

¿Qué hace falta para que un case de un switch caiga al siguiente?

Escribir fallthrough explícitamente al final del case. Por defecto Go NO cae: cada case termina solo, sin necesidad de break. Es lo contrario a C/Java/JS.

Ejercicios

  1. Escribí un bucle que imprima los números del 1 al 20 usando la Forma 1 (clásica) del for.
  2. Reescribí ese mismo bucle usando la Forma 2 (solo condición), para internalizar que reemplaza al while.
  3. Recorré un slice []string{"rojo","verde","azul"} con range e imprimí índice y valor; después hacelo descartando el índice con _.
  4. Escribí un switch sin condición que clasifique una temperatura en "frío" (< 10), "templado" (10 a 25) y "calor" (> 25).
  5. Usando for infinito + break, simulá un contador que se detiene cuando llega a 7, e imprimí cuántos pasos dio.

🧠 Autoevaluación

1. ¿Cuántos bucles distintos tiene Go?

Go tiene un único bucle, for. No existen while ni do-while: el "mientras" se logra con for condicion { }.

2. En for i, v := range frutas, ¿qué valor toma v?

range devuelve (índice, valor): i es el índice y v es el valor. Un error típico es escribir for v := range frutas creyendo que v es el valor, cuando en realidad es el índice.

3. En un switch de Go, ¿qué pasa al final de un case por defecto?

Al revés que C/Java/JS: en Go el break es implícito. Cada case corta solo. Si querés que caiga al siguiente, lo pedís explícitamente con fallthrough.
