De Mid a Senior

El curso original te llevó de cero a "puedo aportar a un equipo". Este track te lleva a "puedo decidir, liderar y arquitecturar".

Donde estás

Mid · 1–2 años
React + TS + tooling. Sabés cómo hacer. Te pasan tareas y las cumplís bien.
→

Donde vas

Senior · 3+ años
Sabés qué hacer y por qué. Decidís stack. Auditás. Mentoreás. Hablás con product y diseño con argumentos.

🎯 Filosofía del track

  • Trade-offs > recetas. Un senior no busca "la respuesta correcta" — encuentra la mejor para SU contexto.
  • Sistemas > código. La diferencia no es saber más React — es ver el sistema completo: arquitectura, escala, equipo, dinero.
  • Decisiones documentadas. ADRs, RFCs, postmortems. Si no podés explicarlo por escrito, no lo entendés.
  • Mentoring. Ser senior es multiplicar el impacto del equipo, no solo el tuyo.
  • Producir > consumir. Después de cada módulo escribís un ADR o un blog post. La pluma fija el conocimiento.

📋 Prerequisitos (qué tenés que dominar antes)

  • El curso CS-FE base completo (módulos 1–13).
  • Al menos 1 proyecto real deployado y mantenido.
  • React + TypeScript fluidez (sin pelearte con generics).
  • Git + GitHub workflow profesional (PRs, code review, branches).
  • Lighthouse ≥ 90 logrado al menos una vez.
  • Mentalidad de "leo specs y RFCs" (no solo Stack Overflow).
