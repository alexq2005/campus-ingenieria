Módulo 00 — Introducción & Setup

Bienvenido al salto de la web al móvil. Al terminar este módulo vas a tener una app corriendo en tu propio celular, modificándose en vivo mientras editás el código. Y lo más importante: vas a entender por qué ya sabés casi todo lo necesario.

¿Qué es React Native?

💡 React Native (RN) es un framework para crear apps nativas de iOS y Android escribiendo React. No es una página web metida en una app. Cuando escribís un <Text>, RN lo convierte en un componente de texto nativo de verdad (un UILabel en iOS, un TextView en Android). El resultado se ve y se siente como una app nativa, porque lo es.

La promesa que lo hizo famoso: "aprendé una vez, escribí para todos lados". Con una sola base de código en React, generás la app para iOS y Android.

Web vs React Native: el mismo cerebro, otras piezas

Lo que cambia no es cómo pensás (sigue siendo React: componentes, props, estado, hooks). Cambian las piezas con las que construís la pantalla:

En la web (HTML)En React NativePara qué
<div><View>Contenedor / caja
<p> <span> <h1><Text>Todo el texto
<img><Image>Imágenes
<input><TextInput>Campos de texto
<button> / onClick<Pressable> / onPressBotones / toques
CSS (archivos .css)StyleSheet (objetos JS)Estilos
scroll automático<ScrollView> / <FlatList>Contenido scrolleable
📌 La regla mental: en RN todo el texto va dentro de un <Text>. No podés tirar texto suelto dentro de un <View> como harías en un <div>. Es el error #1 de quien viene de la web.

¿Qué es Expo y por qué lo usamos?

Expo es un conjunto de herramientas que hace que arrancar con RN sea fácil. Sin Expo necesitarías instalar Android Studio, Xcode, SDKs nativos y pelearte con configuración. Con Expo: escribís código y lo ves correr en tu celular al instante, escaneando un QR. Es el camino recomendado para aprender (y para la mayoría de las apps reales).

Setup — paso a paso

1. Verificá Node.js. RN corre sobre Node. En tu terminal:
node --version    # debería decir v18 o superior

Si no lo tenés, instalalo desde nodejs.org (versión LTS).

2. Instalá "Expo Go" en tu celular. Es una app gratis — buscala en la Play Store (Android) o App Store (iPhone). Es la que va a "correr" tu código mientras desarrollás.
3. Creá el proyecto. En la terminal, en la carpeta donde quieras:
npx create-expo-app@latest MiPrimeraApp

cd MiPrimeraApp
npx expo start

Eso levanta un servidor y muestra un código QR en la terminal.

4. Escaneá el QR con Expo Go (en Android desde la app; en iPhone con la cámara). Tu app se abre en tu celular. ¡Listo, ya estás corriendo una app!
⚠️ Importante: tu compu y tu celular tienen que estar en la misma red WiFi para que Expo Go encuentre el servidor. Es la causa #1 de "no me carga".

Tu primer cambio — live reload

Expo crea un archivo principal (App.js o app/index.tsx). Abrilo. Vas a ver algo así:

import { Text, View, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text>¡Hola! Editá esto y guardá.</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
  },
});

Cambiá el texto del <Text>, guardá el archivo, y mirá tu celular: se actualiza solo, sin reiniciar nada. Eso es live reload, y es lo que hace que desarrollar móvil sea adictivo.

🔍 Mirá lo que ya reconocés: es un componente de función que retorna JSX, exactamente como en el Curso de React. Lo único nuevo son <View>/<Text> en vez de <div>/<p>, y que el estilo es un objeto JS en vez de CSS.

Es React — todo lo que sabés se traslada

Para demostrarlo, acá está un componente con estado, igual que lo harías en la web. Un contador que sube al tocar un botón:

import { useState } from 'react';
import { Text, View, Pressable, StyleSheet } from 'react-native';

export default function App() {
  const [cuenta, setCuenta] = useState(0);   // ⬅️ el mismo useState de siempre

  return (
    <View style={styles.container}>
      <Text style={styles.numero}>{cuenta}</Text>
      <Pressable style={styles.boton} onPress={() => setCuenta(cuenta + 1)}>
        <Text style={styles.botonTexto}>Tocá para sumar</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 20 },
  numero: { fontSize: 64, fontWeight: 'bold' },
  boton: { backgroundColor: '#a78bfa', paddingVertical: 12, paddingHorizontal: 24, borderRadius: 10 },
  botonTexto: { color: 'white', fontWeight: 'bold' },
});
useState, props, useEffect, custom hooks, renderizado condicional, listas con .map()… todo funciona igual. Si dominás el Curso de React, ya tenés el 70% de React Native.

Errores típicos de los que vienen de la web

Texto suelto fuera de <Text>. <View>Hola</View> rompe. Tiene que ser <View><Text>Hola</Text></View>.
Buscar el CSS. No hay archivos .css ni clases. Los estilos son objetos JS con StyleSheet.create, y las propiedades van en camelCase (backgroundColor, no background-color).
onClick en vez de onPress. En móvil se "toca", no se "clickea".

Checkpoint — ¿lo tenés claro?

¿React Native genera una página web?

No. Genera una app nativa de iOS/Android. Tus <Text> y <View> se convierten en componentes nativos reales del sistema operativo, no en HTML.

¿Por qué usamos Expo?

Para evitar instalar y configurar Android Studio / Xcode. Expo te deja correr la app en tu celular al instante (escaneando un QR con Expo Go) y se ocupa de toda la complejidad nativa.

¿Tengo que aprender un lenguaje nuevo?

No. Es JavaScript/TypeScript y React, lo mismo que ya sabés. Cambian los componentes (View/Text) y la forma de estilar (objetos JS), pero la lógica es idéntica.

Ejercicios

  1. Creá el proyecto con create-expo-app y corré la app en tu celular con Expo Go.
  2. Cambiá el texto inicial por tu nombre y un emoji. Confirmá que el celular se actualiza solo al guardar.
  3. Escribí el contador del ejemplo. Tocá el botón y verificá que el número sube.
  4. Agregá un segundo botón "Reiniciar" que vuelva la cuenta a 0 (pista: setCuenta(0)).
  5. Cambiá el color del botón y el tamaño del número editando el StyleSheet.
