🗺️ Ruta de Aprendizaje

De cero a desarrollador empleable. Un orden sugerido para recorrer los 5 cursos y los proyectos — para que sepas siempre qué sigue y por qué.

💡 No es una jaula, es un mapa. Podés saltar etapas si ya sabés algo. Pero el orden está pensado para que cada cosa se apoye en la anterior: programás mejor si entendés la web, y construís mejor si ya programás. Regla de oro: en cada etapa, construí el proyecto antes de seguir. Lo que no se construye, no se aprende.
Etapa 0 · Cimientos

¿Cómo funciona todo esto?

⏱ 1-2 semanas · Frontend

Antes de escribir código, entendé el terreno: qué pasa cuando abrís una página, qué es el HTML/CSS, y cómo se ve la estructura de un documento. Sin esto, todo lo demás es magia.

📖 Estudiá Cómo funciona la Web HTML — estructura CSS — estilos CSS Layout (Flexbox/Grid)
🛠️ Construí Una página personal estática Tu primera web, sin JS todavía.
Etapa 1 · Pensar como programador

Lógica y un lenguaje de verdad

⏱ 3-4 semanas · Python

Python es el mejor primer lenguaje: leíble y poderoso. Acá aprendés variables, control de flujo, funciones, estructuras de datos y POO — los conceptos que sirven en cualquier lenguaje.

📖 Estudiá Python: intro → POO (M00-M06) Errores y archivos (M07-M08)
🛠️ Construí Tic-Tac-Toe (lógica) Análisis de datos con pandas
Etapa 2 · Las herramientas del oficio

La terminal y el sistema

⏱ 2-3 semanas · Linux

Todo dev vive en la terminal. Aprendé a moverte en Linux, manejar archivos, procesos, permisos y a automatizar con bash. Esto te acompaña el resto de tu carrera.

📖 Estudiá Linux: shell → permisos (M00-M06) Bash scripting (M09)
🛠️ Construí Web Scraper + cron Automatizá (servicio real)
Etapa 3 · Hacer que las cosas pasen

JavaScript, el DOM y la asincronía

⏱ 3-4 semanas · Frontend

El lenguaje de la web. Manipular la página (DOM), responder a eventos, y traer datos de APIs (async). Acá tus páginas dejan de ser estáticas.

📖 Estudiá JS Fundamentos DOM y Eventos Async y Fetch API
🛠️ Construí Weather Dashboard (API) Notas Markdown
Etapa 4 · Frontend profesional

React y TypeScript

⏱ 5-6 semanas · React

Cómo se construye el frontend hoy: componentes, estado, hooks, routing, y tipado con TypeScript. Es lo que pide el mercado.

📖 Estudiá React: componentes → hooks TypeScript Next.js + RSC
🛠️ Construí Acortador de URLs (fullstack) Dashboard SaaS (capstone)
Etapa 5 · Lo que sostiene todo

Backend, bases de datos y CS de fondo

⏱ 6-8 semanas · Ing. Sistemas

Para ser senior, no alcanza la UI. Bases de datos, APIs, arquitectura, sistemas operativos y redes — los fundamentos que separan a quien copia código de quien lo entiende.

📖 Estudiá Modelado y SQL (M19) Sistemas Operativos (M14) Redes (M15)
🛠️ Construí API REST + SQL + índices Caché con Redis Stack Docker
Etapa 6 · Elegí tu camino

Especialización

⏱ continuo · IA/Seg/DevOps Físico

Con las bases sólidas, profundizá en lo que te apasione. Cada rama tiene sus proyectos en la galería.

📖 Ramas 🤖 IA / Datos 🔐 Seguridad 🔌 Computación Física
🛠️ Proyectos insignia Clasificador de imágenes (IA) Cámara con visión (edge) Guardián del Agua (capstone)

🎓 ¿Listo cuándo?

Cuando puedas tomar un proyecto de la galería que nunca hiciste, leer su guía, y construirlo solo de punta a punta. Ahí dejaste de seguir un curso y te convertiste en alguien que construye. Ese es el objetivo de todo el campus.
