Closures: funciones que recuerdan

Un closure es una función que "captura" las variables del scope donde fue creada. Tres contadores independientes, cada uno con su propio n privado:

Contador A

0

Contador B

0

Contador C (con paso personalizado)

0

El código

function crearContador(paso = 1) {
  let n = 0;               // ← esta variable es PRIVADA
  return function(comando) {
    if (comando === 'reset') {
      n = 0;
    } else {
      n += paso;
    }
    return n;
  };
}

const a = crearContador();      // paso=1
const b = crearContador();      // paso=1, independiente de a
const c = crearContador(10);    // paso=10

Observá: cada llamada a crearContador() genera un scope nuevo con su propia n. Las funciones retornadas (a, b, c) siguen teniendo acceso a su n aún después de que crearContador haya terminado.

Dónde se usa esto en la vida real: hooks de React (useState usa closures internamente), módulos privados pre-ES6, memoización, debounce, throttle, y cualquier "factory" que quiera estado interno.
